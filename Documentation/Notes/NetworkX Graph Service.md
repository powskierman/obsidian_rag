### Main Idea
- The NetworkX service maps the structural relationships of the vault based on explicit wiki-links and file organization.

### References
- [[SYSTEM_OVERVIEW_2025.md]]
- Port 8002; Container: `obsidian-graph-service`

### Notes
- **Capabilities**:
    - **Nodes**: ~16,212 Obsidian note files.
    - **Edges**: ~16,268 explicit wiki-links.
    - **Model**: GPT-4o-mini via OpenRouter.
- **Best For**:
    - "Which notes link to my Home Assistant setup?"
    - Discovering orphaned notes or link clusters.
    - Analyzing your vault's manual hierarchy and explicit connections.
