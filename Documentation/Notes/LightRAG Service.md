### Main Idea
- LightRAG provides an entity-centric semantic graph that extracts thousands of concepts and relationships directly from note text using AI.

### References
- [[SYSTEM_OVERVIEW_2025.md]]
- Port 8001; Container: `obsidian-lightrag`

### Notes
- **Capabilities**:
    - **Nodes**: ~24,000 concepts/entities.
    - **Edges**: ~35,000 semantic relationships.
    - **Model**: Kimi K2 (`moonshotai/kimi-k2-0905`).
- **Query Modes**:
    - `local`: Neighborhood exploration.
    - `global`: Community pattern detection.
    - `hybrid`: Combined local + global (recommended).
- **Best For**:
    - Complex conceptual relationships (e.g., CAR-T side effects).
    - Finding connections across unlinked notes.
