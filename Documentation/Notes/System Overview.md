### Main Idea
- A production-grade, local-first RAG system for a 1,676-note Obsidian vault combining multiple retrieval strategies.

### References
- [[SYSTEM_OVERVIEW_2025.md]]

### Notes
- **Core Components**:
    - [[Dual Knowledge Graphs]]: The heart of the system's reasoning capability.
    - [[Vector Search Service]]: Provides semantic similarity search using ChromaDB.
    - [[API Gateway]]: The central orchestration layer for all queries.
    - [[Deep Thinking Agent]]: A multi-step reasoning engine for complex research.
    - [[User Interfaces]]: Modern Next.js and legacy Streamlit interfaces.
- **Key Features**:
    - **Dual Graphs**: Combines entity-centric semantic links with note-centric structure.
    - **Agentic Search**: Breaks down complex questions into sub-queries.
    - **Personal Memory**: Uses `mem0` to remember user context and past interactions.
    - **Real-time Indexing**: Automated file watcher keeps the system up-to-date.
