### Main Idea
- A decision matrix to help users select the most effective retrieval mode based on their specific inquiry type.

### References
- [[SYSTEM_OVERVIEW_2025.md]]

### Notes
| Question Type | Recommended Mode | Reason |
|---------------|------------------|--------|
| **Treatments/Conditions** | `graph` ([[LightRAG Service]]) | Entity-focused concept extraction |
| **Note Navigation** | `notes` ([[NetworkX Graph Service]]) | File-level structural discovery |
| **Topic Synthesis** | `hybrid` | Combined Vector + Graph + LLM reasoning |
| **Complex Research** | [[Deep Thinking Agent]] | Multi-step agentic decomposition |
| **Similarity Search** | `vector` ([[Vector Search Service]]) | Fast semantic matching |
| **Link Analysis** | `notes` ([[NetworkX Graph Service]]) | Structure and relationship mapping |

- **Tip**: When in doubt, start with **`hybrid`** or **Deep Thinking** for the most comprehensive results.
