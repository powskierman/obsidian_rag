# Combined Search Workflow

Use this sequence when you want both recall and reasoning.

1. **Vector**: get top source notes quickly.
2. **Hybrid**: add a graph answer + ranked sources.
3. **Graph**: dig into relationships when you need link structure.

Typical flow:

- Start with `vector` to see what exists.
- Switch to `hybrid` for final answers with sources.
- Use `graph` only if you need explicit relationships or paths.
