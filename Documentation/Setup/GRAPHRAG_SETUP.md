# GraphRAG Setup (Optional)

GraphRAG is optional and only needed if you plan to use the GraphRAG indexing scripts.

## Steps

1. Set required API keys in `.env` (OpenRouter or provider you use).
2. Run the GraphRAG script:
   ```bash
   ./Scripts/index_with_graphrag.sh
   ```

If you do not use GraphRAG, you can ignore this doc.
