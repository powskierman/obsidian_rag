### Notes

1. GPIO Configuration:
    `Backlog GPIO25 258; GPIO26 256; GPIO27 257; GPIO33 259; GPIO34 164; GPIO35 165; SaveData 1`
    Purpose: Sets up the GPIO pins for relays and switches.
2. Set Switch Modes:
    `Backlog SwitchMode5 1; SwitchMode6 1`
    Purpose: Sets door sensors to inverted mode (1 = open, 0 = closed).
3. Set PulseTime for Relays:
    `Backlog PulseTime1 5; PulseTime2 5; PulseTime3 5; PulseTime4 5`
    Purpose: Sets a 0.5-second pulse for all relays (momentary switch behavior).
4. Decouple Switches from Relays:
    `SetOption114 1`
    Purpose: Prevents switches from directly controlling relays.
5. Enable Home Assistant Auto-discovery:
    `SetOption19 1`
    Purpose: Enables automatic discovery in Home Assistant.
6. Set up Rules:
    `Rule1 ON Switch5#State=0 DO Publish stat/garage/leftdoor closed ENDON ON Switch5#State=1 DO Publish stat/garage/leftdoor open ENDON ON Switch6#State=0 DO Publish stat/garage/rightdoor closed ENDON ON Switch6#State=1 DO Publish stat/garage/rightdoor open ENDON Rule1 1 Rule2 ON Switch5#State=0 DO Power1 1 ENDON ON Switch5#State=1 DO Power1 0 ENDON ON Switch6#State=0 DO Power2 1 ENDON ON Switch6#State=1 DO Power2 0 ENDON Rule2 1`
    Purpose: Sets up logic for publishing door states and controlling relays based on sensor inputs.
7. Set Friendly Names:
    `Backlog FriendlyName1 LeftDoor; FriendlyName2 RightDoor; FriendlyName3 AlarmOn; FriendlyName4 AlarmOff`
    Purpose: Assigns meaningful names to the relays for easier identification.
8. ***Warning!! This erases configuration!***
	1. Save Configuration:
	    `Module 0`
	    Purpose: Saves all settings and restarts the device to apply changes.
1. Enable Matter (if not already enabled):
    `SetOption151 1`
    Purpose: Enables Matter support for smart home integration.
10. Monitoring Commands:
    `Status 0`
    Purpose: Shows current state of all switches and relays.
    `GPIO`
    Purpose: Displays current GPIO configuration.
11. MQTT Configuration (if needed):
    `Backlog MqttHost your_mqtt_broker_ip; MqttUser your_username; MqttPassword your_password; Topic GarageMatter`
    Purpose: Sets up MQTT connection for communication with other smart home devices/systems.

This configuration sets up a garage door control system with two doors and an alarm system, using an ESP32 with Tasmota firmware. It includes Matter support for modern smart home integration, rule-based logic for door state reporting and relay control, and proper decoupling of switches and relays for reliable operation.
