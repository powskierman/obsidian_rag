### Notes
- The solution set (within the real number system $\mathbb R$) of an equation or an inequality involving a variable $x$ is the set of all real  $x$ that satisfy the given equation or inequality. 
	- The solution set of the equation $(x+1)(x-3)=0$  is the set $\{-1,3\}$
	- Curly brackets denote a set or collection
	-  The solution set of the inequality 2x + 1 < 7 is the set $\{x \in \mathbb{R} \mid x<3\}$
		- #### :
			- Epsilon ($\in$) means *element of*
			- $\mathbb R$ means *real numbers*
			- | means *such that*
