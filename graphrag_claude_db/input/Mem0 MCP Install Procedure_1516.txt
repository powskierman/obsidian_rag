# Mem0 MCP Server Installation Guide

### Main Idea
- Complete step-by-step installation procedure for setting up Mem0 MCP server on Mac Mini
- Provides persistent memory capabilities for Claude Desktop through Model Context Protocol
- Uses local ChromaDB for vector storage and Ollama for embeddings

### Prerequisites

#### 1. Install Homebrew (if not already installed)
```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```

#### 2. Install UV (Python package manager)
```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

#### 3. Install Ollama
```bash
brew install ollama
```

#### 4. Start Ollama service
```bash
# Start Ollama in the background
brew services start ollama

# Or start manually (will run in foreground)
ollama serve
```

#### 5. Install the nomic-embed-text model
```bash
ollama pull nomic-embed-text:latest
```

### Installation Steps

#### Step 1: Create Project Directory
```bash
# Create the main directory
mkdir -p ~/mem0-mcp-server
cd ~/mem0-mcp-server
```

#### Step 2: Create Environment File
```bash
# Create .env file with your Anthropic API key
cat > .env << 'EOF'
ANTHROPIC_API_KEY=your_anthropic_api_key_here
EOF
```

**Important**: Replace `your_anthropic_api_key_here` with your actual Anthropic API key.

#### Step 3: Create Project Configuration
```bash
# Create pyproject.toml
cat > pyproject.toml << 'EOF'
[project]
name = "mem0-mcp-server"
version = "0.1.0"
description = "Mem0 MCP Server for Claude Desktop"
dependencies = [
    "mem0ai",
    "ollama",
    "chromadb",
    "anthropic",
    "mcp",
    "python-dotenv",
]

[build-system]
requires = ["hatchling"]
build-backend = "hatchling.build"
EOF
```

#### Step 4: Create the MCP Server Script
```bash
# Create the main MCP server file
cat > mcp_server.py << 'EOF'
#!/usr/bin/env python3
"""
Standalone MCP Server for Mem0 with STDIO transport.

This server provides memory operations through the Model Context Protocol (MCP)
using standard input/output for communication with Claude Desktop.
"""

import asyncio
import logging
import os
import sys
from typing import Any, Sequence

from dotenv import load_dotenv
from mcp.server import Server, NotificationOptions
from mcp.server.models import InitializationOptions
import mcp.server.stdio
import mcp.types as types
from mem0 import Memory

# Load environment variables
load_dotenv()

# Initialize logging
logging.basicConfig(level=logging.INFO, format="%(asctime)s - %(levelname)s - %(message)s")
logger = logging.getLogger(__name__)

# Configuration
ANTHROPIC_API_KEY = os.environ.get("ANTHROPIC_API_KEY")
HISTORY_DB_PATH = os.environ.get("HISTORY_DB_PATH", "/tmp/mem0_history.db")

DEFAULT_CONFIG = {
    "version": "v1.1",
    "vector_store": {
        "provider": "chroma",
        "config": {
            "collection_name": "memories",
            "path": "/tmp/chroma_db",
        },
    },
    "llm": {"provider": "anthropic", "config": {"api_key": ANTHROPIC_API_KEY, "temperature": 0.2}},
    "embedder": {"provider": "ollama", "config": {"model": "nomic-embed-text:latest"}},
    "history_db_path": HISTORY_DB_PATH,
}

# Initialize memory instance lazily
_memory_instance = None

def get_memory_instance():
    """Get or create memory instance"""
    global _memory_instance
    if _memory_instance is None:
        try:
            _memory_instance = Memory.from_config(DEFAULT_CONFIG)
            logger.info("Memory instance initialized successfully")
        except Exception as e:
            logger.error(f"Failed to initialize memory instance: {e}")
            raise
    return _memory_instance

# Create the server
server = Server("mem0-mcp-server")

@server.list_tools()
async def handle_list_tools() -> list[types.Tool]:
    """List available tools."""
    return [
        types.Tool(
            name="add_memory",
            description="Add new memories. Use this when the user shares information about themselves, preferences, or asks you to remember something.",
            inputSchema={
                "type": "object",
                "properties": {
                    "text": {
                        "type": "string",
                        "description": "The text content to store as memory"
                    },
                    "user_id": {
                        "type": "string",
                        "description": "User identifier (optional, defaults to 'default_user')"
                    }
                },
                "required": ["text"],
            },
        ),
        types.Tool(
            name="search_memory",
            description="Search through stored memories. Use this EVERY time the user asks questions to find relevant context.",
            inputSchema={
                "type": "object",
                "properties": {
                    "query": {
                        "type": "string",
                        "description": "Search query to find relevant memories"
                    },
                    "user_id": {
                        "type": "string",
                        "description": "User identifier (optional, defaults to 'default_user')"
                    }
                },
                "required": ["query"],
            },
        ),
        types.Tool(
            name="get_all_memories",
            description="Retrieve all stored memories for a user.",
            inputSchema={
                "type": "object",
                "properties": {
                    "user_id": {
                        "type": "string",
                        "description": "User identifier (optional, defaults to 'default_user')"
                    }
                },
                "required": [],
            },
        ),
        types.Tool(
            name="delete_memory",
            description="Delete a specific memory by ID.",
            inputSchema={
                "type": "object",
                "properties": {
                    "memory_id": {
                        "type": "string",
                        "description": "ID of the memory to delete"
                    }
                },
                "required": ["memory_id"],
            },
        ),
        types.Tool(
            name="delete_all_memories",
            description="Delete all memories for a user.",
            inputSchema={
                "type": "object",
                "properties": {
                    "user_id": {
                        "type": "string",
                        "description": "User identifier (optional, defaults to 'default_user')"
                    }
                },
                "required": [],
            },
        ),
    ]

@server.call_tool()
async def handle_call_tool(
    name: str, arguments: dict[str, Any]
) -> list[types.TextContent]:
    """Handle tool calls."""
    try:
        memory = get_memory_instance()
        user_id = arguments.get("user_id", "default_user")

        if name == "add_memory":
            text = arguments["text"]
            result = memory.add(text, user_id=user_id)
            return [types.TextContent(type="text", text=str(result))]

        elif name == "search_memory":
            query = arguments["query"]
            results = memory.search(query, user_id=user_id)
            return [types.TextContent(type="text", text=str(results))]

        elif name == "get_all_memories":
            memories = memory.get_all(user_id=user_id)
            return [types.TextContent(type="text", text=str(memories))]

        elif name == "delete_memory":
            memory_id = arguments["memory_id"]
            memory.delete(memory_id=memory_id)
            return [types.TextContent(type="text", text=f"Memory {memory_id} deleted successfully")]

        elif name == "delete_all_memories":
            memory.delete_all(user_id=user_id)
            return [types.TextContent(type="text", text=f"All memories for user {user_id} deleted successfully")]

        else:
            raise ValueError(f"Unknown tool: {name}")

    except Exception as e:
        logger.error(f"Error handling tool call {name}: {e}")
        return [types.TextContent(type="text", text=f"Error: {str(e)}")]

async def main():
    """Main function to run the server."""
    # Run the server using stdio transport
    async with mcp.server.stdio.stdio_server() as (read_stream, write_stream):
        await server.run(
            read_stream,
            write_stream,
            InitializationOptions(
                server_name="mem0-mcp-server",
                server_version="1.0.0",
                capabilities=server.get_capabilities(
                    notification_options=NotificationOptions(),
                    experimental_capabilities={},
                ),
            ),
        )

if __name__ == "__main__":
    asyncio.run(main())
EOF
```

### Claude Desktop Configuration

#### Step 8: Update Claude Desktop Settings

1. **Open Claude Desktop Settings**
   - Click on Claude Desktop in the menu bar
   - Select "Settings"
   - Click on the "MCP" tab

2. **Add this configuration** (replace any existing mem0 configuration):

```json
{
  "mcpServers": {
    "mem0": {
      "command": "uv",
      "args": [
        "--directory",
        "/Users/[YOUR_USERNAME]/mem0-mcp-server",
        "run",
        "mcp_server.py"
      ]
    }
  }
}
```

**Important**: Replace `[YOUR_USERNAME]` with your actual username. You can find it by running:
```bash
echo $HOME
```

3. **Save and restart Claude Desktop**

### Troubleshooting

#### Common Issues and Solutions:

1. **"Ollama connection failed"**
   ```bash
   # Restart Ollama
   brew services restart ollama
   # Or manually
   ollama serve
   ```

2. **"nomic-embed-text model not found"**
   ```bash
   ollama pull nomic-embed-text:latest
   ```

3. **"Permission denied" errors**
   ```bash
   chmod +x mcp_server.py
   ```

4. **"ANTHROPIC_API_KEY not found"**
   - Edit the `.env` file and add your API key:
   ```bash
   nano .env
   # Add: ANTHROPIC_API_KEY=your_actual_key_here
   ```

#### Checking Logs

If the server isn't working, check Claude Desktop logs:
```bash
# View logs (adjust path for your username)
tail -f ~/Library/Logs/Claude/mcp-*.log
```

### File Structure After Installation

Your final directory structure should look like:
```
~/mem0-mcp-server/
├── .env                    # Your API key
├── pyproject.toml         # Project configuration
├── mcp_server.py          # Main server script
├── .venv/                 # Virtual environment (created by uv)
└── uv.lock               # Dependency lock file
```

### Performance Notes

- **First startup**: May take 10-15 seconds as it initializes ChromaDB
- **Memory location**: Stored in `/tmp/chroma_db` (persists between sessions)
- **History database**: Stored in `/tmp/mem0_history.db`

### Features Provided

- ✅ **add_memory**: Store new information and memories
- ✅ **search_memory**: Search through stored memories (called automatically on user questions)
- ✅ **get_all_memories**: List all stored memories
- ✅ **delete_memory**: Delete specific memories by ID
- ✅ **delete_all_memories**: Clear all memories for a user
