### Notes
-  If things go sideways, reset path:
	- -> PATH=$(getconf PATH)
	- delete ~/esp/esp-idf
	- delete .espressif
-  install pre-requisites:
	- brew install cmake ninja dfu-util
	- or: sudo port install cmake ninja dfu-util
- get repositories:
	- cd ~/esp
	- git clone --recursive https://github.com/espressif/esp-idf.git
	- -> cd esp-idf
	- git checkout v4.4.2
	- git submodule update --init --recursive;
	- ./install.sh
	- -> source export.sh
	-  cd ..
- Install openssl:
	- brew install openssl pkg-config
- Adjust path for openssl:
	- export PKG_CONFIG_PATH=$PKG_CONFIG_PATH:"/opt/homebrew/opt/openssl@3/lib/pkgconfig" 
- Build:
	- cd to project directory
	- set the correct chip target: 
		- idf.py --preview set-target esp32c3
	- -> Adjust environment.  The simplest way to use the partition table is to open the project configuration menu (`idf.pymenuconfig`) and choose one of the simple predefined partition tables under [CONFIG_PARTITION_TABLE_TYPE](https://docs.espressif.com/projects/esp-idf/en/latest/esp32/api-reference/kconfig.html#config-partition-table-type):
		- idf.py menuconfig
			- Choose flash size
	- idf.py build
	- idf.py flash
	- if required:
		- idf.py monitor
