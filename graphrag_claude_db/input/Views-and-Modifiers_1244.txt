1.  It's common to want modifiers that apply only when a certain condition is met

    a.  Use ternary operator

**struct** ContentView: View {
@State **private var** useRedText = false

**var** body: some View {
Button("Hello World") {
// flip the Boolean between true and false
**self**.useRedText.toggle()
}
.foregroundColor(useRedText ? .red : .blue)
}
}

1.  Because SwiftUI watches for changes in our**@State**properties and re-invokes our**body**property, whenever that property changes the color will immediately update.

1.  Create complex view hierarchies

    a.  use properties

        i.  create a view as a property of your own view

        ii. use that property inside your layouts.

**struct** ContentView: View {
**let** motto1 = Text("Draco dormiens")
**let** motto2 = Text("nunquam titillandus")

**var** body: some View {
VStack {
motto1
motto2
}
}
}

3.  You can apply modifiers directly to those properties

    a.  VStack {
        motto1
        .foregroundColor(.red)
        motto2
        .foregroundColor(.blue)
        }

    b.  keeps your**body**code clearer

        i.  avoids repetition

        ii. gets more complex code out of the**body**property

        iii. Can't create one stored property that refers to other stored properties

             i.  create a**TextField**bound to a local property will cause problems

        ```{=html}
        <!-- -->
        ```
        i.  you can create*computed*properties

            i.  **var** motto1: some View { Text("Draco dormiens") }

1.  Split up one large view into multiple smaller views

    a.  Wrap in a custom view

**struct** CapsuleText: View {
**var** text: String

**var** body: some View {
Text(text)
.font(.largeTitle)
.padding()
.foregroundColor(.white)
.background(Color.blue)
.clipShape(Capsule())
}
}

2.  use that**Custom View** inside our original view

    a.  **struct** ContentView: View {
        **var** body: some View {
        VStack(spacing: 10) {
        CapsuleText(text: "First")
        CapsuleText(text: "Second")
        }
        }
        }

1.  Custom View Modifiers

    a.  we can create our own ViewModifiers on top of the built-in ones

    b.  **struct** Title: ViewModifier {
        **func** body(content: Content) -> some View {
        content
        .font(.largeTitle)
        .foregroundColor(.white)
        .padding()
        .background(Color.blue)
        .clipShape(RoundedRectangle(cornerRadius: 10))
        }
        }

    c.  Call it with:

        i.  Text("Hello World")
            .modifier(Title())

    ```{=html}
    <!-- -->
    ```
    a.  Better to create extensions on**View**; easier to use

        i.  **extension** View {
            **func** titleStyle() -> some View {
            **self**.modifier(Title())
            }
            }

    ```{=html}
    <!-- -->
    ```
    a.  Call it with:

        i.  Text("Hello World")
