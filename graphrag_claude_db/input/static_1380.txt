### Notes
-  In C, the `static` keyword is used as a storage class specifier, and its meaning depends on the context in which it's used:

1. **Static Variable**:
   - When `static` is used with a variable inside a function or at the global scope (outside of any function), it means that the variable has static storage duration. This means the variable is allocated memory once and retains its value between function calls.
  
   Example:
   ```c
   int func() {
       static int x = 0; // x retains its value between function calls
       x++;
       return x;
   }
   ```

2. **Static Function**:
   - When `static` is used before the function name, it restricts the function's scope to the translation unit in which it is declared. In other words, the function is only visible within the file where it is defined.

   Example:
   ```c
   static void my_static_function() {
       // This function is only visible within this file
   }
   ```

3. **Static Global Variable**:
   - When `static` is used with a global variable, it limits the scope of that variable to the file in which it is defined. The variable is not visible to other files.

   Example:
   ```c
   // In file1.c
   static int global_var = 10; // This variable is only visible within file1.c
   
   // In file2.c
   extern int global_var; // Error: global_var is not visible in file2.c
   ```

4. **Static Member in a Struct**:
   - When `static` is used to define a member of a struct, it means that the member is shared by all instances of the struct. It's essentially a class-level variable in object-oriented programming.

   Example:
   ```c
   struct Example {
       int regular_member;
       static int static_member; // Shared by all instances of struct Example
   };
   ```

Remember, the meaning of `static` can vary depending on where it's used. It provides a way to control the visibility and lifetime of variables and functions in different contexts.
