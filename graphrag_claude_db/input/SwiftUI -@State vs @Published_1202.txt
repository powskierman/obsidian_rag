### Notes
-   Use `@State` and `@Published` together when you need to combine local state and state that needs to be shared across views.

- `@State` is used to declare local state within a view. Local state is used to store values that are specific to a single view and should not be shared with other views. The `@State` property wrapper creates a binding to the value and automatically updates the view when the value changes.

- `@Published` is used to declare a property within an `ObservableObject` class that needs to be observed and updated by other objects. When you mark a property with `@Published`, it becomes a publisher that emits a new value whenever the property changes.
class Model: ObservableObject {
    @Published var sharedValue: Int = 0
}
Example:
```
struct ContentView: View {
    @State private var localValue: Int = 0
    @ObservedObject var model = Model()
    
    var body: some View {
        VStack {
            Text("Local value: \(localValue)")
            Text("Shared value: \(model.sharedValue)")
            
            Button("Increment Local") {
                localValue += 1
            }
            
            Button("Increment Shared") {
                model.sharedValue += 1
            }
        }
    }
}
```
