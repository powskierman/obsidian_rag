### Notes
| Hotkey | Action                          |
| ------ | ------------------------------- | 
| ⌘N     | New note                        | 
| ⌘⇧N    | New note in new pane            |
| ⌘⌥A    | Insert new note template        |
| ⌘⇧M    | Toggle bullet or numbered list  |
| ⌘W     | Close active pane               | 
| ⌘⇧T    | Undo close pane                 |
| ⌘E     | Toggle reading view             |
| ⌘I     | Toggle italics                  |
| ⌘B     | Toggle bold                     |
| ⌘P     | Command palette                 |
| ⌘⇧D    | Open tables control bar         |
| ⌥0     | Convert URL to preview (iframe) |
| ⌘⇧X    | Maximize active pane            | 
| ⌃[tab]  | Cycle through open panes
