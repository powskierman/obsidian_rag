### Notes
-  New xcode project, swiftui
- Configure project
	- Signing and Capabilities
		- Make sure there is a team and bundle
	- Make corrections in [[info.plist]]
	- Add Homekit capability in Signing and Capabilities
		- Otherwise you get: **Sync operation failed with error: Error Domain=NSCocoaErrorDomain Code=4097 "connection to service named com.apple.homed.xpc"**
- Create [[HomeStore]] swift file for HomeStore class
	- The `HomeStore` class is a [[SwiftUI - Singleton]] that holds the one and only home manager for the app
	- You always create an instance of [`HMHomeManager`](https://developer.apple.com/documentation/homekit/hmhomemanager?language=objc) as the root HomeKit object.
		-    let homeManager = HMHomeManager()
	- The home manager contains an array of homes, each of which has a collection of accessories.
- Create a [[Combine]] cancellable variable of the [[AnyCancellable]] type
	-     var cancellable: AnyCancellable?
