-  Steps to Port the Code to Home Assistant
1. Set Up Home Assistant and ESPHome
Install Home Assistant: Ensure that Home Assistant is installed on your system. It can be on a Raspberry Pi, a virtual machine, or any compatible device.
Install ESPHome Add-on: In Home Assistant, go to the Add-On Store and install the ESPHome add-on. This will allow you to manage and configure your ESP32 devices directly from Home Assistant
2. Configure ESPHome for Your ESP32
```
esphome:
  name: gazebo_controller
  platform: ESP32
  board: esp32dev

wifi:
  ssid: "YOUR_WIFI_SSID"
  password: "YOUR_WIFI_PASSWORD"

# Enable logging
logger:

# Enable Home Assistant API
api:

ota:

sensor:
  - platform: dht
    pin: GPIO2
    model: DHT22
    temperature:
      name: "Gazebo Temperature"
    humidity:
      name: "Gazebo Humidity"
    update_interval: 60s

switch:
  - platform: gpio
    pin: GPIO0
    name: "Gazebo Fan"
    inverted: true]
    (https://www.perplexity.ai/search/make-me-a-mermaid-sequence-dia-ASp_oo9uTg681IfZGmePaw)
```
3. Write the ESPHome Configuration
Create a YAML Configuration File: This file will define the behavior of your ESP32 device. Below is a basic template that you can expand upon based on the original code's functionality:
text
esphome:
  name: gazebo_controller
  platform: ESP32
  board: esp32dev

wifi:
  ssid: "YOUR_WIFI_SSID"
  password: "YOUR_WIFI_PASSWORD"

# Enable logging
logger:

# Enable Home Assistant API
api:

ota:

sensor:
  - platform: dht
    pin: GPIO2
    model: DHT22
    temperature:
      name: "Gazebo Temperature"
    humidity:
      name: "Gazebo Humidity"
    update_interval: 60s

switch:
  - platform: gpio
    pin: GPIO0
    name: "Gazebo Fan"
    inverted: true

4. Flash the Configuration to ESP32
Compile and Upload: Use the ESPHome Web UI to compile and upload the configuration to your ESP32. This process will flash the ESPHome firmware onto your device

5. Integrate with Home Assistant
Add ESPHome Device to Home Assistant: Once the ESP32 is online, it should automatically appear in the Home Assistant integrations page. You can then add it to your dashboard and start using it to control your gazebo's environment.
6. Test and Expand Functionality
Test the Setup: Ensure that the temperature and humidity readings are accurate and that the fan switch operates as expected.
Expand Functionality: You can add more sensors or actuators as needed, such as additional relays or different types of sensors, by modifying the YAML configuration file.
