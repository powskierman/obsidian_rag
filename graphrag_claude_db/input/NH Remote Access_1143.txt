### Notes
- Remote router management
	- go to `quickconnect.to` and enter site ddns:
		- `lapointenh`
		- `trailside`
- Synology VPN
	- Access is using the following DDNS and port:
	-  NH DDNS: `lapointenh.synology.me:443`
		- password: `331Tra1l$ide`
		- same port and password for trailside
	- On iPhone or iPad, use the VPN Plus app to connect.
	- On Mac, use the DDNS address and port in a browser
- Site-to-site VPN
	- Site-to-Site VPN service allows local networks in different physical locations to securely communicate with each other over the Internet.
	- [Site-to-Site VPN  VPN Plus Server](https://kb.synology.com/)
	- [[Nokia FastMile 5G Gateway Passthrough]]
