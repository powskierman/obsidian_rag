# Sensor request-response cycle
Date: 2023-12-18

### Notes
- #### Summary:
	- The cycle starts with a request to fetch the state of an entity.
	- A WebSocket message is sent with a unique `messageId`.
	- When a response arrives, it's matched with the `messageId` and processed.
	- The completion handler updates the UI with the new state.
- Detail:
- #### 1. Initiating State Request
- The cycle begins in `GarageSocketManager`'s `fetchInitialState()` method:
- 
```
self?.websocket.fetchState(for: "binary_sensor.left_door_sensor") { state in     DispatchQueue.main.async {         self?.leftDoorClosed = (state == "off")         print("Initial state for left garage door fetched: \(state ?? "nil")")     } }```

- `fetchState(for:completion:)`: This method is called to fetch the initial state of the left garage door.
- The completion block is defined to update `leftDoorClosed` and print the fetched state.

#### 2. Sending the WebSocket Request

In `HassWebSocket`, `fetchState(for:completion:)` handles the creation and sending of the WebSocket request:

```swift
public func fetchState(for entityId: String, completion: @escaping (String?) -> Void) {
    messageId += 1
    completionHandlers[messageId] = completion

    let stateRequest: [String: Any] = [
        "id": messageId,
        "type": "get_states",
        "entity_id": entityId
    ]

    do {
        let data = try JSONSerialization.data(withJSONObject: stateRequest, options: [])
        if let jsonString = String(data: data, encoding: .utf8) {
            sendTextMessage(jsonString)
        }
    } catch {
        print("Error creating state request message: \(error)")
        completion(nil)
    }
}
```
 
- `messageId` is incremented to uniquely identify this request.
- The completion handler for this request is stored in `completionHandlers`.
- The request message is constructed and serialized into JSON.
- `sendTextMessage(jsonString)`: The JSON string is sent as a WebSocket message.

#### 3. WebSocket Response Handling

When a WebSocket response is received, it's processed in `GarageSocketManager`:

```swift
func didReceive(event: Starscream.WebSocketEvent, client: Starscream.WebSocketClient) {
    // ...

    case .text(let text):
        handleWebSocketTextResponse(text)

    // ...
}

private func handleWebSocketTextResponse(_ text: String) {
    guard let data = text.data(using: .utf8),
          let jsonResponse = try? JSONSerialization.jsonObject(with: data, options: []),
          let responseDict = jsonResponse as? [String: Any] else {
        print("Error parsing WebSocket text response")
        return
    }

    if let id = responseDict["id"] as? Int, completionHandlers.keys.contains(id) {
        handleStateResponse(responseDict, messageId: id)
    } else {
        // Handle other types of responses
    }
}

```
- When a text event is received, `handleWebSocketTextResponse(text)` is called.
- This method parses the JSON response and checks if it matches a known `messageId`.
- If it matches, `handleStateResponse(responseDict, messageId: id)` is called.

#### 4. Processing the Response

`handleStateResponse` in `GarageSocketManager` processes the response:

```swift
private func handleStateResponse(_ response: [String: Any], messageId: Int) {
    if let result = response["result"] as? [String: Any],
       let state = result["state"] as? String {
        if let completion = completionHandlers[messageId] {
            completion(state)
            completionHandlers.removeValue(forKey: messageId)
        }
    } else {
        print("Error or unexpected format in state response: \(response)")
    }
}

```

- This method extracts the state from the response.
- The stored completion handler corresponding to the `messageId` is retrieved and called with the state.
- The completion handler is removed from `completionHandlers`.

#### 5. Completion Handler Execution

Back in `GarageSocketManager`'s `fetchInitialState()`, the completion handler updates the UI:

```swift
self?.leftDoorClosed = (state == "off")
print("Initial state for left garage door fetched: \(state ?? "nil")")

```

- This block updates `leftDoorClosed` based on the received state.
- A log statement prints the fetched state.
