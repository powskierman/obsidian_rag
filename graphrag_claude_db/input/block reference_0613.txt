### Notes
- ***To create a block reference:
- Method 1: Obsidian auto-generates block ids when you refer to a block. The way to refer to a block is to first link to a file like so `[[testFile` then press the carret symbol, `[[testFile^`. Now Obsidian will show a list of all the blocks in the file `testFile`. When you select one of these blocks Obsidian will automatically create a block ID for that block.]] [[Obsidian Hotkeys#^f70033]]
- Method 2: You can navigate to the file which contains the block you want to reference (in our case it is `testFile`) and then at the end of the block you can add your custom block ID `^your-alpha-numeric-ID-here` [[Obsidian Tags#^tags]]
