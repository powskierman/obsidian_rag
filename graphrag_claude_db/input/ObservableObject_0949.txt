### Notes
-  When a class conforms to the ObservableObject protocol, it gains access to a @Published property wrapper that can be applied to any properties that should trigger updates when their values change. This wrapper generates an event whenever the property's value changes, which notifies any dependent views that they need to redraw themselves.
- To use an ObservableObject in SwiftUI, you typically:
	- Create an instance of the class in the view that needs to observe it,
	- Use the @ObservedObject property wrapper to declare a dependency on it. 
- This causes the view to be redrawn whenever the @Published properties of the observed object change.
