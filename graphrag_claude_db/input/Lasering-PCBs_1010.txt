- # Lasering PCBs

1.  From Kicad Plot to PDF

2.  Import PDF in Photoshop

    a.  Export as PNG

3.  Go to svgcreator.com

    a.  Create SVG

4.  Import svg into Laserweb

    a.  Reset size

    b.  Settings:

        i.  Laser Fill Path

        ii. Line Distance: .15

        iii. Laser Power 4

        iv. Margin 0.1

        v.  Passes 1

        vi. Cut Rate 1000
