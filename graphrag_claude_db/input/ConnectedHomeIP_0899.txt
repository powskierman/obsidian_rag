### Notes
- Errors and Challenges:
	- Zap error: Zap is very painful to use, Use the non-zap, esp-matter version of the lighting app.
- zap
	- GUI endpoint and cluster configuration
	- Start with example configuration and copy to project folder
	- Install:
		- [zapdevelopment-instructions.md at master · project-chipzap · GitHub](https://github.com/project-chip/zap/blob/master/docs/development-instructions.md)
		- Works flawlessly.  If errors, make sure arch is x86 including node version.
	- [ZCL Advanced Platform (ZAP) - Good instruction manual](https://developers.home.google.com/matter/tools/zap)
	- 
- cd ~/esp or ~/osp (Intel esp)
- get project from github:
	-  git clone --recursive https://github.com/project-chip/connectedhomeip.git
	- to update:
		- git submodule sync --recursive
- Install openssl and pkg-config:
	- brew install openssl pkg-config
- Expose CHIP package to pkg-config:
	- x86:
		- cd /usr/local/lib/pkgconfig
		- ln -s ../../Cellar/openssl@1.1/1.1.1s/lib/pkgconfig/* .
	- arm64:
		- ```export PKG_CONFIG_PATH=$PKG_CONFIG_PATH:"/opt/homebrew/opt/openssl@3/lib/pkgconfig"```
- cd connectedhomeip
- source scripts/activate.sh
- Go to app folder
	- gn gen out/host
	- ninja -C out/host
- If missing dependency errors:out/blink
		- pip install click
		- pip install lark
		- pip install jinja2
		- pip install stringcase
- [[Format ESP32]]
	- If there is a weird error, download latest version of esptool
		- 
	- esptool.py --chip esp32s3 --port /dev/cu.usbmodem4401  erase_flash
- Flash ESP32
```esptool.py --chip esp32s3 --**port /dev/cu.usbmodem4401** --baud 460800 --before default_reset --after hard_reset \

write_flash -z --flash_mode dio --flash_freq 40m --flash_size detect \

0x01000 bootloader.bin \

0x08000 partition-table.bin \

0xe0000 ota_data_initial.bin
```
