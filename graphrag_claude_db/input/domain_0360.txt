- The domain is what you start with ($x$); 
	- The domain is all possible $x$ values 
- #### Rules to Find the Domain of a Function
	- $f(x)$ = polynomial: the domain is the set of all real numbers.
	- $f(x) = {1\over x}$: The set of all real numbers except x≠0.
	- $f(x) = \sqrt x$: The set of all real numbers such that x ≥ 0.
	- $f(x) = \ln x$: The set of all real numbers such that x > 0.
			$$y=−\sqrt{−2x+3y}$$
