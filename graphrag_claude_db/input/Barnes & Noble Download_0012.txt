### Notes

Nook recommends using the Nook for Android app. Therefore, it is easy to install the Nook for Android app on an Android emulator, download Nook books on the Android emulator, and then remove DRM with our powerful tool – **Epubor Ultimate**
### Step 1. Download and install Android emulator on Windows/Mac.

No matter on Windows or Mac, you can use the **[Google Android Studio](https://developer.android.com/studio)**. Choose the correct computer operation system. Then follow the on-screen instructions to install it.

Then create virtual device, Use Pixel 9 API 27. It's the only one that supports rooting and the B&N app.  After create the Android device, just launch it.

![create virtual device](https://www.epubor.com/images/uppic/create-virtual-device.gif)

Note: There are many Android emulators on the market. It is better to use Google Android Studio as we recommended.

### Step 2. Install Nook for Android App on Android emulator and download Nook books to Android emulator.

[_Nook for Android APK Download_](https://download.epubor.com/nookandroid.apk)

Download the nook for android apk from the above link and then drag it to the Android emulator to install it.

Then login to Nook for Android, locate the book you wish to download, and click the cloud icon to download it.

![download to nook books](https://www.epubor.com/images/uppic/download-nook-books-2.png)

### Step 3: Remove Nook DRM on Android emulator with Epubor Ultimate.

- Install adb:
- List android devices:
	- `adb devices`
- Export the path:
	- `export ANDROID_HOME=/Users/michel/Library/Android/sdk`
	- `export PATH=$ANDROID_HOME/platform-tools:$PATH`
- Access the shell
	- `adb shell`
- Enable Root Access
	- `su`
- Locate the Nook Books Directory:
	•	`/data/data/bn.ereader/files/B&N Downloads/Books`
	•	Super user is required to access this directory
	
- Download the ebooks.  At the CLI:
	- `adb pull /data/data/bn.ereader/files/B\&N\ Downloads/Books ~/Desktop/NookBooks`
