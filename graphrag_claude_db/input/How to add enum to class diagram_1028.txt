# How to add enum to class diagram
Date: 2023-01-10

### Backlink
[[Visual Paradigm Class Diagrams]]

### Reference
-  
### Notes
-  Click the drop-down for “Class” on the left side of a class diagram, and select “Enumeration”.
- Drag the enumeration onto your diagram.
- Name it (ex: “PharmacyType”).
- Right click on the enumeration class, and click Add -> Enumeration Literal. Add your literals (ex: Retail, Wholesale, Specialty and Distribution). Press escape when you are done adding literals.
- Right click on the class that will reference the enumeration, and select Add -> Attribute
- Type in ex: “pharmacyType: PharmacyType”, and press enter. Press escape.
- If you open the specification for the new attribute, it should show the enumeration class as the Type.
