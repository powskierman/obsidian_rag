# SwiftUI - @EnvironmentObject
Date: 2023-03-01

### Backlink
[[AI Tools MoC]]

### Notes
- use `@ObservedObject` to share data between a model and a single view, and `@EnvironmentObject` to share data between a model and multiple views.
-  Let's say you have a class called User that stores some information about the current user, such as their name and age. You want to share this data across multiple views in your app. Here is how you can do it:

- Make your User class conform to ObservableObject
- Mark its properties with @Published. 
	- This will allow SwiftUI to observe any changes in the data and update the views accordingly.
```
class User: ObservableObject {
    @Published var name: String
    @Published var age: Int

    init(name: String, age: Int) {
        self.name = name
        self.age = age
    }
}
```
- Create an instance of your User class and attach it to a view using environmentObject().
	- This will make the user object available to any view that needs it.
```
struct ContentView: View {
    var body: some View {
        // Create a user object with some initial values
        let user = User(name: "Alice", age: 25)

        // Attach the user object to a view using environmentObject()
        ProfileView().environmentObject(user)
    }
}
```
- Finally, you need to use @EnvironmentObject in any view that wants to access the user data. 
	- You can use dot notation to access the properties of the user object.
```
struct ProfileView: View {
    // Use @EnvironmentObject to get the user object from the environment
    @EnvironmentObject var user: User

    var body: some View {
        VStack {
            Text("Hello, \(user.name)!")
            Text("You are \(user.age) years old.")
            Button("Increase Age") {
                // Update the user's age by 1
                user.age += 1
            }
        }
    }
}
```
