# Add keypair to keychain
Date: 2023-01-18

### Backlink

### Reference

### Notes
-  on macOS, you can store additional SSH keys in the macOS Keychain.
	- Open up ~/.ssh/config and add the following lines:

```
Host *
UseKeychain yes
```

- You can now add keys with:
```
ssh-add -K ~/keyfile.pem
```
- The keys will be stored in the keychain and persist across reboots. 
- The keys need to be read-writable only by you:

```
chmod 600 ~/keyfile.pem
```
- You can also add public key via CLI:
	- [[Add keypair to keychain]]
