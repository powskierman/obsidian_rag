### Notes
- If using connectedhomeIP build, go to: [[ConnectedHomeIP]]
- If the bootstrapping fails, delete the folder **.environment/** and start again.
- If ERROR: This script was called from a virtual environment, can not create a virtual environment again:
	- deactivate
- Reset path:
	- -> ls -als
- get esp-idf repository:
	- git clone --recursive https://github.com/espressif/esp-idf.git
	- cd ~/esp/esp-idf
	- git checkout v4.4.3
	- git submodule update --init --recursive
	- ./install.sh
	- source export.sh
	-  cd ..
- Get esp-matter repository
	- Use X86 shell
	- git clone --recursive https://github.com/espressif/esp-matter.git
	- cd  ~/esp/esp-matter
	- ./install.sh
	-  source export.sh
	- export IDF_CCACHE_ENABLE=1
	- cd ..
- Install openssl:
	- brew install openssl pkg-config
- Adjust path for openssl:
	- -> export PKG_CONFIG_PATH=$PKG_CONFIG_PATH:"/opt/homebrew/opt/openssl@3/lib/pkgconfig" 
	- 
- Build:
	- If zap error:
		- Zap is very painful to use, use the non-zap, esp-matter version of the lighting app.
	- Clean environment
		- cd esp-matter/connectedhomeip/connectedhomeip
		- yes | rm -r .environment
	- cd examples/lighting-app/esp32
	- Adjust environment 
		- idf.py menuconfig
			- Choose flash size
	- Important!: idf.py -p /dev/cu.usbmodem3101 erase-flash
	- idf.py --preview set-target esp32s3
		- This should do a idf.py build
		- If mdns error:
			- idf.py add-dependency mdns
		- if compile error delete build directory
	- idf.py flash monitor
- Provisioning
	- Connect to wifi
		- In the matter monitor: 
			- matter wifi connect ssid password
		- Use ios Home app to connect
			- Scan code from https://docs.espressif.com/projects/esp-matter/en/main/esp32/developing.html
		- ![](https://docs.espressif.com/projects/esp-matter/en/main/esp32/_images/matter_qrcode_20202021_3840.png)
