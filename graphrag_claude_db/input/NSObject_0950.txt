### Notes
-  NSObject is a root class in the Objective-C programming language that defines the basic interface for all Objective-C objects. It is the base class for most Objective-C classes, and provides a set of default behaviors and methods that are inherited by its subclasses.

- NSObject provides a set of fundamental features to objects in Objective-C, including:
	- Memory management through reference counting with the retain, release, and autorelease methods.
	- Identification of objects using the isEqual: and hash methods.
	- Object initialization and deallocation with init and dealloc methods.
	- The ability to perform runtime introspection with methods like class, respondsToSelector:, and performSelector:.
- In short, NSObject provides the foundation for object-oriented programming in Objective-C, and is the starting point for creating new classes in the language.
