### Notes
-  The -> operator in C/C++ is used to access members of a struct or class via a pointer.
In this code snippet, 
```
void sysProvEvent(arduino_event_t *sys_event)
{
    switch (sys_event->event_id) {
    ...
}
```
- `sys_event` is a pointer to an `arduino_event_t` struct. So `sys_event->event_id` is accessing the event_id member of the struct that `sys_event` points to.
- Some key points:
	- sys_event is a pointer, not a normal struct variable.
	- The -> operator dereferences the pointer and accesses the member.
	- It is equivalent to (\*sys_event).event_id - dereferencing the pointer explicitly before accessing the member.
	- For normal struct variables you would use . instead of -> to access members. But for pointer variables you need ->.
