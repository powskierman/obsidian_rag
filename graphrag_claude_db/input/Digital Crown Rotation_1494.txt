### Notes

-  Example: (from Documents/SwiftUI Projects/Tests/CrownTest)
```swift TI:"Example" FOLD
import SwiftUI

struct ContentView: View {
    @State private var crownValue = 0.0
    var body: some View {
        Text("Received Value:\(crownValue, specifier: "%.1f")")
            .focusable()
            .digitalCrownRotation( $crownValue)
    }
}

#Preview {
    ContentView()
}
```
- In this example, the `@State` variable `count` represents the number displayed on the screen. The `count` variable is adjusted continuously until the rotation stops.

- Example from Halcyon 2.0 for watch
```swift TI:"Halcyon 2.0" FOLD
.digitalCrownRotation($currentTemperature, from: 10, through: 30, by: 1, sensitivity: .low)
```
