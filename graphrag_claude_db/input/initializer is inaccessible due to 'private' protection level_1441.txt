# initializer is inaccessible due to 'private' protection level
Date: 2024-02-16

### Backlink
[[Swift MOC]]

### Reference
-  
### Notes
 
```swift FOLD
private struct A {
  private let string: Strin
  ...
}

struct B {
  func foo() {
    let a = A(string: "bar")
    ...
  }
}
```

 The initializer's access level is only as accessible as the _least accessible_ instance variable.

If I make the `string` instance variable anything other than `private`, the error goes away:

```swift
private struct A {
  let string: String
  // synthesized initializer:
  // init(string: String)
}
```

So given that `B` can now read `A`'s `string`, it can also access `A`'s initializer.
