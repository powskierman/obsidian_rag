### Notes
-  Halcyon is an ESP32 project to control multiple Fujitsu Halcyon split units.  It features a custom PCB and code.
- The Kicad PCB files can be found at: /Volumes/Docs/Electronics/Projects/Kicad/ESP32Halcyon
- The original Blynk project can be found at: /Volumes/Docs/Electronics/Projects/NH/Halcyon/ESP32_IR_Fujitsu9.0 
	- [[Changes-from-Halcyon-8.2-to-9]]
- HalcyonHass will eventually replace Halcyon.  
	- It is based on HomeAssistant as a backend 
	- It uses the REST API to send data back and forth to the app and control the HVAC.  
	- The HVAC in turn is controlled by ESPHome's climate implementation
	- The Watch app can be found at:

	- The phone app can be found at:
