### Notes
- [![](https://github.com/Xinyuan-LilyGO/T-Display-S3/raw/main/image/T-DISPLAY-S3.jpg)](https://github.com/Xinyuan-LilyGO/T-Display-S3/blob/main/image/T-DISPLAY-S3.jpg)
- Screen is 320 x 170 pixels 
- Clear screen with :
	- ```lcd.fillScreen(TFT_BLACK);```
- Common functions
	- Include library:
		- ```#include "TFT_eSPI.h"```
	- Create instance:
		- ```TFT_eSPI lcd = TFT_eSPI();```
	- Initialize instance:
		- ```lcd.init();```
	- Fill screen with color:
		- ```lcd.fillScreen(TFT_RED);```
	- Set text color:
		- ```lcd.setTextColor(TFT_<color>);```
	- Write text with specific font
		- ```lcd.drawString("text",<x>,<y>,<)```
- A Sprite is an invisible graphics screen that is kept in the processors RAM. Graphics can be drawn into the Sprite just as they can be drawn directly to the screen. Once the Sprite is completed it can be plotted onto the screen in any position.
