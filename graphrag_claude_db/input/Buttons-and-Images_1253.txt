- 1.  Simple Button

print("Button was tapped")

}) {

}

3.  3 ways to create Image

    a.  Image("pencil")

        i.  will load an image called "Pencil"

    ```{=html}
    <!-- -->
    ```
    a.  Image(decorative: "pencil")

        i.  will load the same image, but won't read it out for users who have enabled the screen reader.

    ```{=html}
    <!-- -->
    ```
    a.  Image(systemName: "pencil")

        i.  will load the pencil icon that is built into iOS.

        ii. This uses Apple's SF Symbols icon collection

    ```{=html}
    <!-- -->
    ```
    a.  Example

Button(action: {

print("Edit button was tapped")

}) {

HStack(spacing: 10) {

Image(systemName: "pencil")

Text("Edit")

}

}
