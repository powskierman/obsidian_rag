### Main Idea
How to install OpenWebUI natively (without Docker) for local LLMs and Ollama on Mac (Apple Silicon).

---

## Prerequisites
- Homebrew installed
- Node.js LTS (v20.x) using nvm (do not use Homebrew’s node)
- Python 3.11 (not 3.14+)—install via Homebrew: `brew install python@3.11`
- Ollama installed and running natively

---

## Installation Steps

1. **Clone Repository**
`cd ~/dev`  
`git clone [https://github.com/open-webui/open-webui.git](https://github.com/open-webui/open-webui.git)`  
`cd open-webui`

2. **Check and Use Correct Node Version**
`nvm install 20  
nvm use 20  
node -v # Should be v20.x.x  
npm -v # Should be 10.x.x`

3. **Install Frontend Dependencies**
`npm install --legacy-peer-deps  
export NODE_OPTIONS="--max-old-space-size=4096"`

4. **Build Frontend**
`npm run build`
`npm run preview # Access at [http://localhost:4173](http://localhost:4173/)`

5. **Backend Setup**
`cd backend  `
`python3.11 -m venv venv  `
`source venv/bin/activate  `
`pip install --upgrade pip  `
`pip install -r requirements.txt  `
`bash start.sh`

#### Or directly if start.sh fails:
uvicorn open_webui:app --host 0.0.0.0 --port 8080

6. **Start Ollama**
`ollama serve`
Runs at [http://localhost:11434](http://localhost:11434/)


7. **Web App Setup**
- In browser, open the preview server URL.
- Complete admin setup.
- Configure backend in settings: set backend to http://localhost:8080.
- Set Ollama endpoint: http://localhost:11434.

---

### Troubleshooting

- **404 /api/config?**: Backend must be running at port 8080.
- **Dependency Errors?** Use Node v20 (not v23+), Python 3.11 (not 3.14+).
- **Missing npm packages?** Install manually via `npm install package-name`.
