- ## List of ESPHome CLI Commands

| Command | Purpose |
| --- | --- |
| `esphome run <config.yaml>` | Validate, compile, upload firmware, and open console/logs (OTA or USB) |
| `esphome run <config.yaml> --device <serial port>` | Same as above, but uploads via a specified serial port (for USB flashing) |
| `esphome logs <config.yaml>` | Connects to a device and shows live logs (defaults to OTA/API, or USB with `--device`) |
| `esphome logs <config.yaml> --device <serial port>` | Show live serial logs from a device connected by USB |
| `esphome config <config.yaml>` | Only validates the configuration file, does not build or upload firmware |
| `esphome compile <config.yaml>` | Validates and compiles the firmware without uploading |
| `esphome upload <config.yaml> --device <serial port or IP>` | Upload already compiled firmware to device (useful with remote or local USB) |
| `esphome wizard <config.yaml>` | Launches an interactive wizard to create a new device configuration YAML |
| `esphome dashboard config_dir` | Starts the ESPHome Dashboard (web UI) in the specified config directory |
