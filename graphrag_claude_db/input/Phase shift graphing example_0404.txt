- A basic function $\sin(x)$ with no additional parameters, intersects its midline at $(0,0)$ and has a maximum point at (${2 \pi \over 4},1$) which is $({π \over 2},1)$ 
!
- Graph $h(x)=4\sin({\pi \over 4})x+({3 \pi \over 4})+2⁡$
	1. The transformation from $\sin⁡(x)$ to $\sin({\pi \over 4})x$ is a horizontal stretch by a factor of $4 \over \pi$, so the maximum point's horizontal distance from the origin is stretched from $\pi \over 2$ to ${\pi \over 2} \over {\pi \over 4}$ which is  ${\pi \over 2} \times {4 \over \pi}$ which is 2.
		!
	2. The transformation from $\sin({\pi \over 4})x$ to $4\sin({\pi \over 4})x$ is a vertical stretch by a factor of 4, so the maximum point's vertical distance from the origin is stretched from 1 to 4.
				!
	3. The transformation from $4\sin({\pi \over 4})x$ to $4\sin({\pi \over 4})x+({3 \pi \over 4})+2⁡$, which is equivalent to $4\sin({\pi \over 4}(x+3))+2⁡$, is a translation to the left by 3 units and a translation upwards by 2 units.
	4. As a result of these transformations, the intersection point with the midline is now at (−3,2) and the maximum point is at (−1,6).
		!
