### Notes
-  Here are the basic steps to revert a commit in Git using git revert:
- Run git log and find the commit hash you want to revert. Let's say it's 0b1d055.
- Run git revert with the commit hash: `git revert 0b1d055`
	- This will create a new commit that reverses the changes made in 0b1d055.
	- If there are conflicts, Git will open your editor to resolve them. Resolve the conflicts and save the file.
- Once resolved, Git will make a new commit reverting the changes.
- Push the changes to remote:  
	- `git push origin <branch-name>`
- Some tips on using git revert:
	- It creates a new commit that reverses the changes of an existing commit. The reverted commit remains in the history.
	- Use -n option to do a "dry run" and preview changes first.
	- To revert a merge commit, use git revert -m 1 <merge_commit_hash>.
	- Multiple commits can be reverted with git revert <commit1> <commit2> etc.
		- Use git log and git show to inspect commits before reverting.
- So in summary, git revert lets you reverse commits by creating new commits - useful for undoing changes safely.
