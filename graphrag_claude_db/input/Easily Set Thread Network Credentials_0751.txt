-  To set the network credentials easily, use the TLV found in Home Assistant/Settings/Integrations/Thread/info:
	- To use this dataset to join the network, you would use the OpenThread CLI command:

	`dataset set active 0e080000000000010000000300000f35060004001fffe0020888749381b60a52ff0708fdfefb46ee79408405103152491ee6c3e2e2eff1cb3ae26a0fbe030e68612d7468726561642d613564660102a5df0410a2c886995a7564e79d05b5ffe358d8b90c0402a0f7f8`

	- Followed by:

	`dataset commit active thread start`

	- This method of setting the entire dataset at once is more efficient and ensures all parameters are set correctly in a single operation.
