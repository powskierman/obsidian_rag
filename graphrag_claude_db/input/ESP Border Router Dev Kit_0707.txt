### Notes
-  Install is simple:
	- cd to esp folder:
		- `cd /Users/michel/esp/esp-idf`
	- `./install.sh`
	- `. ./export.sh`
- Build the RCP Image
	- `cd /Users/michel/esp/esp-idf/examples/openthread/ot_rcp`
	- `idf.py set-target esp32h2`
	- `idf.py build`
- Configure ESP Thread Border Router
	- cd to project folder:
		- `cd /Users/michel/esp/esp-thread-br/examples/basic_thread_border_router`
	- `idf.py set-target esp32s3`
	- `idf.py menuconfig`
		- Set WiFi credentials:
			- In menu, go to Example Connection Configuration
			- Enter SSID and password
		- Set Thread credentials:
			- In menu, go to Component config → OpenThread → Thread Operational Dataset
			- enter [[Thread Network Keys]]
		- enable automatic start mode in the menuconfig:
			- under "ESP Thread Border Router Example -> Enable the automatic start mode in Thread Border"[ref](https://docs.espressif.com/projects/esp-thread-br/en/latest/dev-guide/build_and_run.html)
		- enable the web server:
			- Enable all features in Menuconfig -> ESP Thread Border Router Example
- Build and Run the Thread Border Router:
	- `idf.py build`
	- connect to USB2 on Espressif border router board
	- `idf.py flash`
		- If needed do: 
		- `idf.py -p <port> flash monitor`
		- Port can be found with: 
			- `ls /dev/{tty,cu}.*`
		- monitor with coolterm
- The GUI is at:
		- `http://192.168.0.xxx:80/index.html`
