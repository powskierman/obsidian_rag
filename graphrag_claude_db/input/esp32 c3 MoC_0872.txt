### Notes
- 32SLed is platformio project
- 32S board only has 2M of flash.  Requires these settings:
	- Board:  ESP32C3
	- upload speed: 460800
	- cpu frequency: 160mhz
	- flash frequency: 80mhz
	- flash size 2mb
	- partition scheme: minimal
- Was able to upload only with Arduino IDE
