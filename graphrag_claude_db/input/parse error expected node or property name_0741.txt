### Notes
-  This is due to bad devicetree formatting. Each node should be separated by curly braces.  This is wrong:
```
/{
    chosen {
        zephyr,console = &usb_cdc_acm_uart;
        zephyr,shell-uart = &usb_cdc_acm_uart;

    };


    zephyr_udc0: &usbd {
        compatible = "nordic,nrf-usbd";
        status = "okay";

        usb_cdc_acm_uart: cdc-acm-uart {
            compatible = "zephyr,cdc-acm-uart";
            status = "okay";
        };
    };
};
```
It should be:
```
/{
    chosen {
        zephyr,console = &usb_cdc_acm_uart;
        zephyr,shell-uart = &usb_cdc_acm_uart;

    };
};
zephyr_udc0: &usbd {
    compatible = "nordic,nrf-usbd";
    status = "okay";

    usb_cdc_acm_uart: cdc-acm-uart {
        compatible = "zephyr,cdc-acm-uart";
        status = "okay";
    };
};
```
