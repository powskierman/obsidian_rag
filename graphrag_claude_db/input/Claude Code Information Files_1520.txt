### Notes
- 1. Create a CLAUDE.md File
	Write a primary instruction file called  CLAUDE.md  and place it at the project root. Use this file to:
		•	Define project goals
		•	Outline coding conventions
		•	List allowed tools and workflows
		•	Keep the file streamlined, focusing only on essential, non-obvious guidance
2. Add Project Memory Files
	Maintain additional files for persistent context such as:
		•	Decisions and insights gained during the project
		•	Relevant background, terminology, or requirements
		•	Reusable patterns or mistakes to avoid Claude Code will read these files at the start of each session, providing background memory.
3. Set Up Slash Command Files
	Within a  .claude/commands/  directory, save frequently used prompts as individual files. This lets you:
		•	Quickly re-inject complex prompts
		•	Avoid filling up your main prompt window with boilerplate text
		•	Standardize instructions for repetitive or complex actions
4. Configure Subagent Settings
	In a  .claude/agents/  directory, add configuration files for specialized subagents (e.g., for testing, code review, or documentation). This:
		•	Keeps the main session’s memory clear
		•	Isolates context for specialized tasks
		•	Lets agents “swap in” focused memory on demand
5. (Optional) Integrate a Memory MCP Server
	For truly persistent, cross-session memory:
		•	Connect Claude Code with a compatible Model Context Protocol [[MCP memory server]]
		•	Use the server’s API or built-in integrations for semantic search and automatic context retention
		•	Enables seamless recall of information from prior sessions, even across projects
These structured steps enable persistent, self-refreshing context in Claude Code, dramatically improving project continuity and developer productivity.
