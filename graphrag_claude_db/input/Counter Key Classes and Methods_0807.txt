### Notes
-  WCSession Setup and Activation:
	- WCSession is established in the Counter class, which is marked as ObservableObject for SwiftUI integration.
	- In the init method of Counter, the WCSession.default is accessed and its delegate is set to an instance of SessionDelegater, another custom class.
	- The session is then activated with self.session.activate(). This step is crucial for establishing the connection between the devices.
- Message Transfer Between Watch and iPhone:
	- The increment and decrement functions in the Counter class use session.sendMessage to send a message from the watch to the iPhone. The message contains the updated count value in a dictionary format, e.g., `["count": count]`.
	- The SessionDelegater class, which conforms to WCSessionDelegate, handles the receptionn of messages. It has a method `session(_:didReceiveMessage:)` that is called when a message is received from the paired device.
	- Inside this method, the received count is extracted from the message and sent to a PassthroughSubject, which is a Combine publisher. This allows the count updates to be observed and reacted to in the SwiftUI view.
- ObservableObject and SwiftUI Integration:
	- The Counter class is an ObservableObject, which makes it possible to use it with SwiftUI's reactive interface.
	- The `@Published` property wrapper is used for the count variable, enabling SwiftUI views to automatically update when this value changes.
	- The subject (a PassthroughSubject) is bound to the count property, ensuring that updates from the Watch Connectivity session are reflected in the UI.
- ContentView: SwiftUI View:
	- The ContentView struct defines the UI of the app, using the Counter object as a @StateObject.
	- It provides buttons for incrementing and decrementing the counter, with actions linked to the increment and decrement methods of the Counter object.
	- It also displays the current count, which updates in response to changes in the Counter object's count property.
- Handling WCSessionDelegate Methods:
	- The SessionDelegater class implements several WCSessionDelegate methods, although most are not used in this demo (e.g., sessionDidBecomeInactive, sessionDidDeactivate, sessionWatchStateDidChange).
	- The key method used is `session(_:didReceiveMessage:)` for receiving messages from the paired device.
