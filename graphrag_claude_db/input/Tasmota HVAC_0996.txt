### Notes
-  Incorporating Tasmota-irhvac into your solution will streamline the control of your Fujitsu Halcyon HVAC splits using Matter-enabled Tasmota32 devices. Tasmota-irhvac is a specialized firmware that includes support for HVAC IR remote control, making it easier to send the correct IR commands to your HVAC units.

### Step-by-Step Procedure

#### Requirements

1. **Hardware**:
   - ESP32 device (flashed with Tasmota-irhvac firmware)
   - Infrared (IR) transmitter module
   - Fujitsu Halcyon HVAC splits

2. **Software**:
   - Tasmota-irhvac firmware with Matter support
   - MQTT broker (if using MQTT for communication)
   - Home Assistant (or another Matter-compatible smart home controller)
   - IR codes for Fujitsu Halcyon (integrated in Tasmota-irhvac)


#### Step 1: Flashing Tasmota-irhvac Firmware

1. [**Install Tasmota link - Use Edge**](https://tasmota.github.io/install/)
2. Or **Download Tasmota-irhvac**:
   - The web installer will install Tasmota automatically.  
   - Or Download the latest Tasmota-irhvac firmware from the [Tasmota releases page](https://github.com/arendst/Tasmota/releases).

2. **Flash the Firmware**:
   Use tools like esptool.py to flash the firmware onto your ESP32 device. Connect the ESP32 to your computer via USB and run:
   ```bash
   esptool.py --chip esp32 --port /dev/ttyUSB0 erase_flash
   esptool.py --chip esp32 --port /dev/ttyUSB0 write_flash -z 0x1000 tasmota-irhvac.bin
   ```
   Adjust the port and firmware file name as needed.

#### Step 2: Configuring Tasmota-irhvac

1. **Connect to Tasmota Web Interface**:
   Connect to the ESP32's Wi-Fi access point (usually named `tasmota-XXXX`). Open a browser and navigate to `192.168.4.1` to configure your Wi-Fi credentials.

2. **Access Web Interface**:
   After the ESP32 connects to your home Wi-Fi, find its IP address (from your router's DHCP list) and access the Tasmota web interface.

3. **Enable Matter Support**:
   In the Tasmota web interface, navigate to **Configuration** > **Configure Other** and set `SetOption151` to `1` to enable Matter support.

4. **Configure IR Transmitter**:
   - Connect the IR transmitter to the ESP32. Commonly, the IR LED's signal pin goes to a GPIO pin on the ESP32.
   - In the Tasmota web interface, go to **Configuration** > **Configure Module** and set the correct GPIO pin to `IRsend`.

5. **Configure HVAC Controls**:
   - In the Tasmota web interface, navigate to **Configuration** > **Configure Module** and select `Fujitsu A/C` under the IR protocols.
   - Use the console commands to set up the HVAC unit, e.g., `IRhvac {"Vendor":"Fujitsu","Model":1,"Power":"On","Mode":"Cool","FanSpeed":"Auto","Celsius":"On","Temp":23}`.

#### Step 3: Integrate with Matter

1. **Configure Matter Endpoint**:
   - In the Tasmota web interface, go to **Configuration** > **Configure Matter**.
   - Add a new endpoint for the IR control of the HVAC, setting the appropriate parameters for your device.

2. **Commissioning**:
   - Commission the Tasmota-irhvac device to your Matter controller (e.g., Home Assistant). Follow the Matter commissioning process by scanning the QR code provided by Tasmota or entering the manual pairing code.

#### Step 4: Home Assistant Integration (Optional)

1. **Install Matter Integration**:
   - Ensure Home Assistant is set up with Matter support. Follow the [Home Assistant Matter integration guide](https://www.home-assistant.io/integrations/matter/).

2. **Add Tasmota Device**:
   - Add the Tasmota32 device to Home Assistant through the Matter integration.
   - Configure automations and controls in Home Assistant to send the appropriate IR commands to control your HVAC.

#### Step 5: Testing and Automation

1. **Test Commands**:
   - Test sending commands from the Tasmota web interface or Home Assistant to ensure the HVAC responds correctly.

2. **Set Up Automations**:
   - Create automations in Home Assistant to control your HVAC based on conditions like time, temperature, or other sensors.

By following these steps, you can control your Fujitsu Halcyon HVAC splits using Matter-enabled Tasmota32 devices with the specialized Tasmota-irhvac firmware. This integration leverages the capabilities of Tasmota-irhvac to manage IR commands efficiently, providing a seamless smart home experience.

For further details, refer to the [Tasmota-irhvac documentation](https://tasmota.github.io/docs/IRHVAC/) and the [Tasmota Matter documentation](https://tasmota.github.io/docs/Matter/).
