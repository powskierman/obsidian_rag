### Basic Setup

**Installation:**
```bash
pip install lightrag-hku
```

**Initialize LightRAG:**
```python
from lightrag import LightRAG
from lightrag.llm import ollama_model_complete, ollama_embedding

# Initialize LightRAG
rag = LightRAG(
    working_dir="./lightrag_db",
    llm_model_func=ollama_model_complete,
    embedding_func=ollama_embedding,
    llm_model_name="qwen2.5:7b"  # or qwen2.5-coder:32b
)

# Build knowledge graph from vault
for note in vault_notes:
    rag.insert(note.content)

# Query with graph awareness
result = rag.query(
    "How does my treatment relate to outcomes?",
    mode="hybrid"  # Combines graph + vector search
)
```

**Integration Script:**
```python
# test_lightrag.py
from lightrag import LightRAG
from lightrag.llm import ollama_model_complete, ollama_embedding
import os
from pathlib import Path

# Vault path
VAULT_PATH = "/Users/michel/Library/Mobile Documents/iCloud~md~obsidian/Documents/Michel/"

# Initialize LightRAG
rag = LightRAG(
    working_dir="./lightrag_db",
    llm_model_func=ollama_model_complete,
    embedding_func=ollama_embedding,
    llm_model_name="qwen2.5:7b"
)

# Index medical notes subset
medical_path = Path(VAULT_PATH) / "Tech" / "AI" / "RAG"
for md_file in medical_path.glob("*.md"):
    with open(md_file, 'r', encoding='utf-8') as f:
        content = f.read()
        rag.insert(content)
        print(f"Indexed: {md_file.name}")

# Test queries
test_queries = [
    "How does Yescarta relate to my current monitoring plan?",
    "What factors led to choosing CAR-T over transplant?",
    "Visualize my treatment timeline"
]

for query in test_queries:
    print(f"\nQuery: {query}")
    result = rag.query(query, mode="hybrid")
    print(f"Result: {result[:200]}...")
```

**Resource Requirements:**
- Storage: +100MB for graph database
- RAM: +2GB during operations (36GB available ✅)
- Initial indexing: ~30 minutes for 1,584 files
- Query time: +5 seconds for graph traversal

**Configuration Options:**
```python
rag = LightRAG(
    working_dir="./lightrag_db",
    llm_model_func=ollama_model_complete,
    embedding_func=ollama_embedding,
    llm_model_name="qwen2.5:7b",
    # Optional parameters:
    chunk_size=1200,           # Adjust for your notes
    chunk_overlap=200,         # Entity context preservation
    max_token_size=4096,       # LLM context window
    enable_llm_cache=True,     # Speed up repeated queries
)
```
