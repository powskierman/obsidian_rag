### Notes
-  AnyCancellable is a type-erasing cancellable object in the Combine framework of the iOS SDK. It provides a way to store a cancellable object without needing to know its concrete type.
- In [[Combine]], when you subscribe to a publisher, you get back a Cancellable object that you can use to cancel the subscription and stop receiving output.
- The type of the Cancellable object depends on the specific publisher you're subscribing to, which can make it difficult to store and manage a collection of cancellable objects with different types.
- This is where AnyCancellable comes in. It's a type-erasing wrapper around a Cancellable object that allows you to store it in a variable or collection without needing to know its concrete type.
