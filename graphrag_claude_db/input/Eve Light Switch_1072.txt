### Notes
- [[Eve Loft Switch QR Code.jpg]]
- Install:
	- Install switch in Home using QR code
		- Adds device to border router
	- Remove device from Home
		- Allows device to be added to Home Assistant
	- Turn breaker off and on
	- Put device in pairing mode:
		- 2 fingers, 10 seconds, yellow flashing light
	- In Home Assistant, go to HomeKit Device and add Eve light switch
	- Go to notifications, new devices discovered
		- Switch will be listed
	- Pair
	- Pairing code will be requested
		- 8 digit code above
		- Important!!  Format as:
			- xxx-xx-xxx
			- Otherwise, misleading error message
