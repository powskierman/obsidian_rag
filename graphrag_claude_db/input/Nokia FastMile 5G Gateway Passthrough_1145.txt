# Nokia FastMile 5G Gateway Passthrough
Date: 2024-11-13

### Backlink
[[Nokia Fastmile 5G Gateway]]

### Reference

### Notes
- To safely enable remote access through a Nokia FastMile 5G Gateway and Synology RT2600ac, follow these steps. This approach will configure a DMZ and port forwarding setup to allow traffic to pass from the Nokia gateway to your Synology router, minimizing double NAT problems and ensuring remote access works reliably.

Step 1: Configure the Nokia FastMile 5G Gateway

Since Rogers does not support direct bridge mode, we’ll place your Synology RT2600ac in the DMZ of the Nokia gateway.

	1.	Access the Nokia Gateway’s Admin Panel:
	•	Open a browser and enter the IP address of the Nokia gateway (usually 192.168.1.1 or found on the device’s label).
	•	Log in with the admin username and password (check the back of the gateway for these).
	2.	Enable DMZ for Your Synology Router:
	•	In the gateway’s admin panel, go to Network Settings %3E DMZ.
	•	Find the DMZ Host option.
	•	Enter the IP address of your Synology router (e.g., 192.168.1.2).
	•	Make sure the Nokia gateway assigns a static IP to the Synology router via DHCP Reservation.
	3.	Disable UPnP on the Nokia Gateway (Optional but recommended for security):
	•	Navigate to UPnP Settings and disable it.
	•	Configure port forwarding:
		- Port 8001 needs to be forwarded
	4. Disable the firewall as what we want is bridging.  DMZ and disabled firewall will accomplish this. 
	5.  Optionally, disable wifi
	6. Save Settings and Reboot the gateway.

Step 2: Configure Your Synology RT2600ac Router

With the Nokia gateway set to forward all traffic to the Synology router, you now need to configure the RT2600ac.

	1.	Assign a Static IP for Synology Router:
	•	In the RT2600ac admin interface (default IP: 192.168.0.1):
	•	Go to Network Center > Internet > Connection.
	•	Set the WAN IP to DHCP, and it will receive the IP from the Nokia gateway.
	2.	Port Forwarding for Remote Access:
	•	In Network Center > Port Forwarding, click Create.
	•	Add rules for the services you want remote access to (e.g., Synology DSM, VPN, or media services):
	•	Example for DSM:
	•	Protocol: TCP
	•	External Port: 8001
	•	Internal IP: 192.168.0.1 (Synology router’s IP)
	•	Internal Port: 8001
	3.	Enable QuickConnect or DDNS (Optional):
	•	Navigate to Control Panel > External Access.
	•	Use Synology QuickConnect or set up DDNS (Dynamic DNS) to make your router accessible with an easy-to-remember hostname instead of an IP address.

Step 3: Verify and Secure Remote Access

	1.	Test Port Forwarding:
	•	Use tools like canyouseeme.org to ensure your forwarded ports are open and accessible.
	2.	Enable Firewall Rules:
	•	On the Synology router, go to Network Center > Security and configure a firewall to block unnecessary traffic while allowing only specific services.
	3.	VPN Configuration (Recommended for Secure Remote Access):
	•	Configure the VPN server on your Synology router (via VPN Server package) to safely access your home network remotely without exposing all ports to the internet.

Optional: Handle Double NAT Issues

	•	If you still encounter issues with double NAT (e.g., online gaming or certain services):
	•	Leave UPnP enabled on the Nokia Gateway while disabling it on the Synology router ￼.

This setup ensures secure remote access through the Nokia FastMile gateway while leveraging the Synology RT2600ac’s advanced networking capabilities. If any issues arise, consider contacting Rogers for further assistance, as some carrier configurations might limit the DMZ or port forwarding options ￼ ￼.>)
