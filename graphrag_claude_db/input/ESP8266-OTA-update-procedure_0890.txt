CheckForUpdates is a library to update OTA an ESP8266 sketch

the procedure is to:

1-compile new binary

2-Copy binary to /var/www/http/FOTA/<project>

3-Rename Binary to mac address of device

4-Create text file named <mac_address>.version with incremented FW_VERSION

ESP8266 will then notify via Blynk and update OTA to new version.





Edit sketch for new functionality

Change version number

Compile sketch

Copy bin

Change to directory pointed at by fwUrlBase

Make subdirectory pointed at by project

Copy resulting bin file from compilation (Found in release or debug subdirectory)

Rename .bin

Start winscp and open directory pointed at by fwUrlBase

Rename bin to <esp MAC address>.bin

Edit <esp MAC address>.version to new version number
