# Similarities and Differences between Matter and HomeKit Data Models
Date: 2023-03-28

### Notes

| Matter | HomeKit |
| --- | --- |
| Node: A single device or group of devices that can be addressed and managed as a single unit | Accessory: A single device that can be added to a HomeKit network |
| Zone: A collection of nodes that are grouped together based on their physical location or function | Zone: A collection of rooms that are grouped together based on their physical location or function |
| Room: A physical location within a home that contains one or more nodes or accessories | Room: A physical location within a home that contains one or more accessories |
|  |  |
| Nodes can represent individual devices or small groups of devices | Accessories represent individual devices |
| Zones represent larger collections of devices that are grouped together based on their location or function | Zones represent collections of rooms that are grouped together based on their location or function |
| Nodes have unique identifiers that allow them to be addressed and controlled by other devices in the network | Accessories have unique identifiers that allow them to be addressed and controlled by other devices in the network |
| Nodes can be a part of multiple zones | Accessories can be assigned to specific rooms and zones |
| Nodes can be controlled individually or as part of a group within a zone | Accessories can be controlled individually or as part of a group within a room or zone |
| Nodes can be used to set up automations and scenes | Accessories can be used to set up automations and scenes |
|  |  |
| Matter networks are typically designed to be more open and interoperable | HomeKit networks are typically designed to be more secure and focused on Apple devices |
| Matter is an industry standard with support from multiple companies | HomeKit is a proprietary standard developed by Apple |
| Matter supports multiple network protocols, including Wi-Fi, Ethernet, and Thread | HomeKit supports multiple network protocols, including Wi-Fi, Ethernet, and Bluetooth |
| Matter is designed to work with a wide range of devices and platforms | HomeKit is primarily designed to work with Apple devices and platforms |
