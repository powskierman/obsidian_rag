# Xcode - Testing a Framework
Date: 2023-10-03

### Backlink
[[../../../../Programming-Tools/Xcode/Xcode MOC]]

### Notes
-  To test a framework on a simulator, you can't run the framework directly since it's not an executable project (like an app). Instead, you create a test app or use unit tests. Here's how you can do both:

### 1. **Using a Test App**:

1. **Create a New App within the Same Workspace**:
    - Open your framework project in Xcode.
    - Go to `File` > `New` > `Project`.
    - Select `iOS` > `App` and click `Next`.
    - Give it a name (e.g., `FrameworkTestApp`) and save it in the same directory as your framework.

2. **Link Your Framework to the Test App**:
    - Select the `FrameworkTestApp` target in Xcode.
    - Go to the `General` tab.
    - Under `Frameworks, Libraries, and Embedded Content`, click `+`.
    - Add your framework.

3. **Use Your Framework**:
    - In the `ViewController.swift` of `FrameworkTestApp`, import and use your framework.
    - For example, if your framework's name is `MyFramework`, you'd do:
      ```swift
      import MyFramework
      ```

4. **Run the Test App**:
    - Select the desired simulator from the list of devices in Xcode.
    - Click the `Run` (play) button to launch the app on the simulator.

5. **Test Your Framework's Functionality**:
    - Add functionality from your framework to the app and observe the results in the simulator.

### 2. **Using Unit Tests**:

You can also use unit tests to test the functionality of your framework without needing to create a separate test app.

1. **Add a Test Target to Your Framework**:
    - Select your framework project in the Project Navigator.
    - Go to `File` > `New` > `Target`.
    - Select `iOS` > `Unit Testing Bundle` and click `Next`.
    - Follow the on-screen instructions to add the test target.

2. **Write Unit Tests**:
    - Open the test target you just created.
    - Import your framework and write unit tests for its functionalities.
    - For example:
      ```swift
      import XCTest
      @testable import MyFramework

      class MyFrameworkTests: XCTestCase {
          func testExampleFunction() {
              // Your test code here
          }
      }
      ```

3. **Run the Tests**:
    - Click on the diamond-shaped play button next to each test in the editor or use the `Product` > `Test` menu option to run all tests.
    - Tests will be executed, and Xcode will display the results.

Both methods will allow you to test the functionality of your framework on a simulator. The best method often depends on the specific nature of your framework and your testing requirements.
