### Notes
## Overview
ESPNexUpload is an Arduino library for ESP8266 and ESP32 microcontrollers that enables uploading .tft files to Nextion displays over serial communication.

## Prerequisites

### 1. Arduino IDE Installation
- **Arduino IDE 2.x** (recommended) or Arduino IDE 1.8.x
- **ESP8266 Arduino Core** version 2.5.1 or higher
- **ESP32 Arduino Core** (latest version)

### 2. Board Support Installation

#### For ESP8266:
1. Open Arduino IDE
2. Go to **File → Preferences**
3. In "Additional Board Manager URLs", add:
   ```
   http://arduino.esp8266.com/stable/package_esp8266com_index.json
   ```
4. Go to **Tools → Board → Boards Manager**
5. Search for "ESP8266" and install "ESP8266 by ESP8266 Community"

#### For ESP32:
1. Go to **File → Preferences**
2. In "Additional Board Manager URLs", add:
   ```
   https://espressif.github.io/arduino-esp32/package_esp32_index.json
   ```
3. Go to **Tools → Board → Boards Manager**
4. Search for "ESP32" and install "ESP32 by Espressif Systems"

## Library Installation

### Method 1: Manual Installation (Recommended)
1. Download or clone this repository
2. Copy the entire `ESPNexUpload` folder to your Arduino libraries directory:
   - **Windows**: `Documents\Arduino\libraries\`
   - **macOS**: `~/Documents/Arduino/libraries/`
   - **Linux**: `~/Arduino/libraries/`
3. Restart Arduino IDE

### Method 2: Arduino Library Manager
1. Open Arduino IDE
2. Go to **Tools → Manage Libraries**
3. Search for "ESPNexUpload"
4. Install the library by Ville Vilpas

## Hardware Connections

### ESP8266 (Wemos D1 Mini example)
```
ESP8266    Nextion Display
D5 (GPIO14) → RX
D6 (GPIO12) → TX
GND        → GND
3.3V       → VCC
```

### ESP32
```
ESP32      Nextion Display
GPIO16     → RX
GPIO17     → TX
GND        → GND
3.3V       → VCC
```

**Note**: Pin definitions can be modified in `ESPNexUpload.cpp` if needed.

## Building and Testing Examples

### 1. UploadServer Example
This example creates a web server for uploading .tft files via web interface.

**Setup:**
1. Open **File → Examples → ESPNexUpload → UploadServer**
2. Modify WiFi credentials:
   ```cpp
   const char* ssid = "your_wifi_ssid";
   const char* password = "your_wifi_password";
   ```
3. Select your board:
   - **Tools → Board → ESP8266 Boards → Wemos D1 R2 & mini** (for ESP8266)
   - **Tools → Board → ESP32 Arduino → ESP32 Dev Module** (for ESP32)
4. Select the correct COM port
5. Click **Upload**

**Usage:**
1. Connect to the WiFi network created by the ESP
2. Open browser and go to `http://nextion.local` or the ESP's IP address
3. Upload a .tft file through the web interface

### 2. WifiClient Example
Downloads and uploads .tft files from a web server.

**Setup:**
1. Open **File → Examples → ESPNexUpload → WifiClient**
2. Modify WiFi credentials and file URL
3. Upload to your ESP board

### 3. SPIFFSRead Example
Reads .tft files from SPIFFS filesystem.

**Setup:**
1. Open **File → Examples → ESPNexUpload → SPIFFSRead**
2. Upload the sketch
3. Use Arduino IDE's **Tools → ESP32 Sketch Data Upload** to upload files to SPIFFS

### 4. SDRead Example
Reads .tft files from SD card.

**Setup:**
1. Connect SD card module to ESP
2. Open **File → Examples → ESPNexUpload → SDRead**
3. Upload the sketch

## Compilation Process

### Using Arduino IDE:
1. Open any example sketch
2. Select the correct board and port
3. Click **Verify** (✓) to compile
4. Click **Upload** (→) to upload to board

### Using Arduino CLI (Advanced):
```bash
# Set up Arduino CLI
arduino-cli config init
arduino-cli core update-index
arduino-cli core install esp8266:esp8266
arduino-cli core install esp32:esp32

# Compile an example
arduino-cli compile --fqbn esp8266:esp8266:d1_mini examples/UploadServer/UploadServer.ino
arduino-cli compile --fqbn esp32:esp32:esp32 examples/UploadServer/UploadServer.ino
```

## Troubleshooting

### Common Issues:

1. **"Board not found" error:**
   - Install the correct board support package
   - Select the right board from Tools → Board

2. **"Library not found" error:**
   - Ensure the library is properly installed in the libraries folder
   - Restart Arduino IDE after installation

3. **Compilation errors:**
   - Check Arduino core version (ESP8266 needs 2.5.1+)
   - Ensure all dependencies are installed

4. **Upload failures:**
   - Check COM port selection
   - Try different USB cable
   - Press and hold BOOT button during upload (ESP32)

5. **Nextion display not responding:**
   - Verify wiring connections
   - Check baud rate settings
   - Ensure display is powered on
   - Try different pin configurations

### Debug Mode:
To enable debug output, uncomment this line in `ESPNexUpload.cpp`:
```cpp
#define DEBUG_SERIAL_ENABLE
```

## Library Features

- **ESP8266 Support**: Uses SoftwareSerial
- **ESP32 Support**: Uses HardwareSerial (Serial2)
- **Multiple Upload Methods**: Buffer, Stream, WiFi, SD, SPIFFS
- **Progress Callbacks**: Monitor upload progress
- **Error Handling**: Comprehensive error reporting
- **Baud Rate Detection**: Automatic baud rate detection
- **Sleep/Dim Handling**: Manages display power states
