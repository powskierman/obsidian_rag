### Main Idea

Entity-centric search retrieves complete knowledge graphs around specific entities (people, treatments, concepts), showing all relationships, attributes, and connections rather than just text chunks mentioning the entity.

### Traditional vs Entity-Centric Search

**Traditional RAG Approach:**
```
Query: "Everything about Yescarta"

Returns: List of chunks
- Chunk 1: "Yescarta is a CAR-T therapy..."
- Chunk 2: "I received Yescarta in April..."
- Chunk 3: "Side effects of Yescarta include..."

User must: Mentally synthesize scattered information
```

**Entity-Centric Search (LightRAG):**
```
Query: "Everything about Yescarta"

Returns: Complete entity graph
Yescarta (CAR-T therapy)
├─ Type: Axicabtagene ciloleucel
├─ Mechanism: CD19-targeted CAR-T
├─ Administered: April 2025
├─ Preceded by: R-CHOP chemotherapy
├─ Requires: Lymphodepletion chemotherapy
├─ Side effects:
│  ├─ Cytokine release syndrome (CRS) - Grade 2
│  ├─ Neurotoxicity - Grade 1
│  └─ B-cell aplasia - Persistent
├─ Monitoring:
│  ├─ PET scans (3mo, 6mo)
│  ├─ IgG levels (monthly)
│  └─ CD19+ monitoring
├─ Related concepts:
│  ├─ CD19 antigen
│  ├─ B-cells
│  └─ Immunotherapy
├─ Outcomes:
│  ├─ 3mo: Complete metabolic response
│  ├─ 6mo: Continued remission
│  └─ SUV max: Normalized (<2.5)
└─ Follow-up care:
   ├─ IVIG therapy (monthly)
   ├─ Infection precautions
   └─ Long-term monitoring plan

Complete entity knowledge in structured form!
```

### Notes

**Entity Types in Medical Knowledge:**

1. **Treatments**: R-CHOP, Yescarta, IVIG
2. **Conditions**: DLBCL, B-cell aplasia, CRS
3. **Biomarkers**: IgG, SUV max, CD19+
4. **Procedures**: PET scan, lymphodepletion
5. **Concepts**: Immunotherapy, CAR-T, remission
6. **Medications**: Tocilizumab, prophylactic antibiotics
7. **Side effects**: Neurotoxicity, CRS, fatigue

**Entity Extraction Quality:**

Good extraction captures:
- Entity name and aliases
- Type and classification
- Attributes (dates, values, status)
- Relationships (causes, treats, monitors)
- Context (when, where, why)

**LightRAG Local Mode:**

Entity-centric search uses `mode="local"`:
```python
result = rag.query(
    "Everything about Yescarta",
    mode="local"  # Entity-focused retrieval
)
```

This retrieves the entity and its immediate relationship neighborhood.

**Visualization:**

Entity graphs can be visualized as:
- Network diagrams (nodes + edges)
- Mind maps (hierarchical)
- Timeline views (temporal entities)
- Relationship matrices
