### Notes
- Download and install [Windows 11  UTM Documentation](https://docs.getutm.app/guides/windows/) on your macOS device.
- Run CrystalFetch to download windows
- Obtain a Windows 11 ARM64 ISO file, as UTM supports running Windows on ARM architecture.
- Set up a new virtual machine in UTM using the Windows 11 ISO. Follow the on-screen instructions to complete the installation of Windows 11 within UTM.
