Throughout this book, I am using low-current LEDs in conjunction with logic-chip outputs, because I think this is a good habit to acquire, in case an output powering an LED is also used as a logic input for another chip at some point in the future. For this reason, don’t tie the outputs together from two or more logic gates. — location: [4742](kindle://book?action=open&asin=B013PVRTEK&location=4742) ^ref-22845
