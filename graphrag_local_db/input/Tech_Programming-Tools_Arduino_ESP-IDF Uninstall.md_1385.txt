# Uninstalling ESP-IDF
Date: 2023-09-09

### Notes
Here are the detailed steps to uninstall/reinstall ESP-IDF and Arduino ESP32 core:

**1. Uninstall Arduino ESP32 Core**

- Open Arduino IDE
- Go to Tools > Board > Boards Manager
- Search for "ESP32" and click on it
- Click "Uninstall" button to remove it

**2. Uninstall ESP-IDF VS Code Extension** 

- Open VS Code
- Click Extensions icon
- Find "ESP-IDF" extension
- Click the gear icon and "Uninstall"
- Restart VS Code

**3. Uninstall ESP-IDF**

- Delete the ESP-IDF directory (`rm -rf ~/esp`) 
- Uninstall Python packages:

```
pip uninstall esptool
pip uninstall idf_py
```

- Remove ESP-IDF tools from PATH in `~/.profile` 

**4. Reinstall ESP-IDF**

- Install dependencies from documentation for your OS 
- `git clone -b v4.4 --recursive https://github.com/espressif/esp-idf.git`
- `cd esp-idf`
- `./install.sh` 
- `export PATH="$HOME/esp/esp-idf/tools:$PATH"`
- `python -m pip install --user -r requirements.txt`

**5. Reinstall VS Code Extension**

- Open VS Code
- Go to Extensions
- Search "esp-idf"
- Click Install

**6. Reinstall Arduino ESP32 Core**

- Open Arduino IDE 
- Go to Tools > Board > Boards Manager
- Search "esp32" and install latest version

Let me know if you need any clarification or have issues with these steps!
