### Notes
-  To recover a specific file,
	- Open ccc
	- Press restore button
	- Select source:
		- ccCanmore
	- Right click to browse in finder
		- Navigate to file or folder
		- Drag to source
	- Click on task filter to select specific file and snapshot
	- Drag the snapshot navigator slider to the appropriate snapshot
	- Click the preview button in the ribbon to preview file content
	- Right click on file and choose restore or cancel out of the filter window and press the restore button.
	- To view the event, click the show event button
		- Right click and show transaction details
- To compare content of snapshots:
	- Go to volumes in left pane
	- Click on backup disk
		- Snapshots will appear in the right pane
	- Select 2 or more snapshots
	- Right click and select comparison browser
