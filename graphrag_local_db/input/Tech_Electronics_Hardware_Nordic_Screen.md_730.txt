### Notes
-  Diconnect:
	- `CTL-a \`
- Detach:
	- `CTL-a d, CTL-a CTL-d`
		- Detach the screen session (disconnect it from the terminal and put it into the background). A detached screen can be resumed by invoking screen with the -r option (see Invoking Screen). The -h option tells screen to immediately close the connection to the terminal (‘hangup’).
- Essential Keyboard Shortcuts
All screen commands begin with the prefix `Ctrl-a` (press Ctrl+a, then release before pressing the next key):
	•	`Ctrl-a c`: Create a new window
	•	`Ctrl-a n`: Switch to the next window
	•	`Ctrl-a p`: Switch to the previous window
	•	`Ctrl-a N`: Switch to window number N (0-9)
	•	`Ctrl-a d`: Detach from the current screen session
	•	`Ctrl-a k`: Kill (close) the current window
	•	`Ctrl-a w`: Show a list of all windows
