### Notes
-  Don't print directly in a view.  Use a closure:   
```
let _ = print("Update ContentView")
```

- Since there is no use for print's return type, use an underscore to ignore the value.
- or:
```
	.onAppear {
                  print("Update ContentView")

              }
```
