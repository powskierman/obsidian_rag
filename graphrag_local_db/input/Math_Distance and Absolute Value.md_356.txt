### Notes
- Absolute value: If α ∈ R then the absolute value or magnitude of α, denoted by |α|, is the distance from α to 0, regarded as points on the real number line, so that $$
|\alpha|=\left\{\begin{aligned}
\alpha & \text { if } \alpha \geq 0 \\
-\alpha & \text { if } \alpha<0
\end{aligned}\right.
$$
