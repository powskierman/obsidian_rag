### Notes
-  Connection to the thread network can all take place in prj.conf:
```
CONFIG_OPENTHREAD_NORDIC_LIBRARY_FTD=y
# L2 Openthread Enabling
CONFIG_NET_L2_OPENTHREAD=y
# Generic Networking Options
CONFIG_NETWORKING=y

# Network Parameters
CONFIG_OPENTHREAD_MANUAL_START=n
CONFIG_OPENTHREAD_NETWORK_NAME="home-assistant"
CONFIG_OPENTHREAD_CHANNEL=15
CONFIG_OPENTHREAD_PANID=52326
CONFIG_OPENTHREAD_XPANID="39346471e986abb0"
# CONFIG_OPENTHREAD_NETWORK_MASTER_KEY="DEADDEADDEADDEADDEADDEADDEADDEAD"

#Network Shell
CONFIG_SHELL=y
CONFIG_OPENTHREAD_SHELL=y
CONFIG_SHELL_ARGC_MAX=26
CONFIG_SHELL_CMD_BUFF_SIZE=416

#Additional Settings
CONFIG_MBEDTLS_SHA1_C=n
CONFIG_FPU=y
CONFIG_GPIO=y

```
