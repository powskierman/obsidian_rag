- Find the biggest files for possible deletion to reduce storage requirements
	- sudo find . -type f -exec stat -c '%s %n' {} \;|sort -n|tail -100>BigFiles.txt
- [Reset QNAP NAS](https://www.qnap.com/en/how-to/faq/article/how-can-i-reset-my-nas)
- Starting from QTS 4.4.2, the default password for “admin” is the first MAC address of your NAS without special characters. All letters should be uppercase.
	- For Fatso:  `245EBE0ECC68`
	- For Jumbo: `245EBE100DF8`
