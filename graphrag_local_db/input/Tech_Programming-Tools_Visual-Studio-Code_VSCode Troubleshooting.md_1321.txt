### Notes
-  How do I get IntelliSense to work correctly?
		- <Kbd>CMD-P<Kbd> \(Pallette)
		- C/C++: Edit Configurations (UI)
		- or edit .vscode/c_cpp_properties.json
```C
{
    "configurations": [
        {
            "name": "Mac",
            "includePath": [
                "${default}",
                "/users/michel/Library/Arduino15/packages/esp32/hardware/esp32/2.0.12/tools/sdk/esp32/include/**",
                "/Users/michel/Documents/esp/Examples/common/**",
                "${workspaceFolder}/build/config" //<--!  This is the important one for freeRTOS
            ],
            "defines": [],
            "macFrameworkPath": [],
            "cStandard": "c17",
            "cppStandard": "gnu++17",
            "configurationProvider": "ms-vscode.cmake-tools"
            "compileCommands": "${workspaceFolder}/build/compile_commands.json"
        }
    ],
    "version": 4
```
