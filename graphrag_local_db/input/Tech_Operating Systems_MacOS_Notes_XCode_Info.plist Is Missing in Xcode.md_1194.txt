### Notes
-  Info.plist Is Missing in Xcode
	- First, go to:
	
	```
	Project → Targets → Info → Custom iOS Target Properties
	```
	
	…then edit the properties, just like you would’ve back in `Info.plist`.
	- The first time, Xcode will automatically generate a new `Info.plist` file that’s semi-synced with `Custom iOS Target Properties`. Xcode will later merge them for you.
