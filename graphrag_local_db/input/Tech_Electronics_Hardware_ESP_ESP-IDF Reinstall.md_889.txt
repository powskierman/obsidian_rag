### Notes
-  Here's a detailed, step-by-step process to completely reinstall ESP-IDF both standalone and as a Visual Studio Code add-on:

## Uninstall Existing ESP-IDF

1.  Uninstall the ESP-IDF extension from VS Code:
    
    -   Open VS Code
    -   Go to the Extensions view (Ctrl+Shift+X)
    -   Find the ESP-IDF extension
    -   Click "Uninstall"
    
2.  Remove existing ESP-IDF directories:
    
    -   Delete the `esp` folder in your user directory (e.g. C:\\Users<username>\\esp)
    -   Delete the `.espressif` folder in your user directory
    
3.  Remove ESP-IDF from system PATH:
    
    -   Open System Properties > Advanced > Environment Variables
    -   Remove any ESP-IDF related entries from both User and System variables
    

## Install Standalone ESP-IDF

1.  Download ESP-IDF from [Standard Toolchain Setup for Linux and macOS - ESP32 - — ESP-IDF Programming Guide v5.3 documentation](https://docs.espressif.com/projects/esp-idf/en/stable/esp32/get-started/linux-macos-setup.html)
    
2.  Set up environment variables:
    
    -   Open a command prompt
    -   Navigate to your ESP-IDF directory
    -   Run `export.bat`
    
3.  Verify the installation:
    
    -   In the same command prompt, run: `idf.py --version`
        
    -   It should display the ESP-IDF version
    

## Install ESP-IDF Extension in VS Code

1.  Open Visual Studio Code
2.  Install the ESP-IDF extension:
    
    -   Go to the Extensions view (Ctrl+Shift+X)
    -   Search for "ESP-IDF"
    -   Click "Install" on the official Espressif ESP-IDF extension
    
3.  Configure the ESP-IDF extension:
    
    -   Press Ctrl+Shift+P to open the command palette
    -   Type "ESP-IDF: Configure ESP-IDF extension" and select it
    -   Choose "Express"
    -   Select the same ESP-IDF version you installed standalone
    -   Set the ESP-IDF directory to where you installed it (e.g. C:\\esp\\esp-idf)
    -   Set the ESP-IDF tools directory (usually C:\\Espressif)
    -   Click "Install" and wait for the process to complete
    
4.  Verify the VS Code setup:
    
    -   Open a new VS Code window
    -   Press Ctrl+Shift+P
    -   Type "ESP-IDF: New project" and create a sample project
    -   Try building the project using the ESP-IDF extension commands
