# Visual Paradigm - Add array as parameter
Date: 2023-01-10

### Backlink
[[Visual Paradigm Class Diagrams]]

### Notes
-  To add an array as a parameter to a class or method in a class diagram in Visual Paradigm, you can follow these steps:

- Open your class diagram in Visual Paradigm.
- Right-click on the class or method in which you want to add the array parameter, then select "Properties" from the context menu.
- In the Properties dialog, switch to the "Operation" tab.
- Click on the "Add" button to add a new operation to the class or method.
- In the "Name" field, enter a name for the operation, and in the "Return Type" field, enter the data type of the array you want to add, followed by square brackets "[]" (e.g., "String[]").
- In the Parameters section, you can add new parameter by clicking + button
- in the name field enter the parameter name and in the Type field enter the data type of array (e.g. String[] )
- Click OK to close the Properties dialog. The array parameter will now be added to the class or method in your class diagram.
