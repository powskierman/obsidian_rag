### Notes
-  In SwiftUI, you typically don't use delegates like you would in UIKit. Instead, you can use the @ObservedObject or the @StateObject property wrappers to create an observable object that can be shared across views. Assuming HomeManager is a class that conforms to ObservableObject, you can create an instance of it as a @StateObject in your view and assign it to your HomeStore singleton like this:
```
@ObservedObject var homeManager = HomeManager()
HomeStore.shared.homeManager = homeManager
```
Then, make sure your view conforms to the ObservableObject protocol and implements any necessary methods or properties that the HomeManager might need to update the view.
