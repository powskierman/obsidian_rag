### Notes
-  The node.warn() function allows you to send custom messages to the debug window without affecting the msg object. Here’s how you can modify your function:
```node
// Output the variable states to the debug window
node.warn(`halted: ${halted}, pulseActive: ${pulseActive}`);
```
