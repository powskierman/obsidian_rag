## Common Commands

| Action                | Command Example                                             |
| --------------------- | ----------------------------------------------------------- |
| Start system service  | `container system start`                                    |
| Pull image            | `container image pull alpine:latest`                        |
| Run container (shell) | `container run -t -i alpine:latest sh`                      |
| Run container (bg)    | `container run --name my-web-server --detach --rm web-test` |
| List containers       | `container ls`                                              |
| Exec command          | `container exec my-web-server ls /`                         |
| Stop container        | `container stop my-web-server`                              |
| Stop system service   | `container system stop`                                     |

Apple’s Containerization CLI offers a familiar, Docker-like experience, but with native macOS integration and stronger security isolation. For advanced features and troubleshooting, refer to the official documentation and GitHub repository.
