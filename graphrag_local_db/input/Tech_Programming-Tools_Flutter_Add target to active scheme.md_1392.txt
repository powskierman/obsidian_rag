# Add target to active scheme
Date: 2023-11-15

### Backlink
[[Xcode Troubleshooting]]

### Notes
-  To add a new target to an active scheme in Xcode:
- Create a New Target:
	- Go to the Project Navigator by clicking on the first icon in the toolbar on the top-left side of Xcode.
	- Select your project from the list to view the project settings.
	- In the project editor, click on the '+' button at the bottom of the targets list.
		- Choose a template for your new target (e.g., iOS, WatchOS, macOS, etc.) 
- Edit the Scheme:
	- Click on the scheme dropdown menu, then select 'Manage Schemes'.
	- Add the New Target to the Scheme:
		- In the Manage Schemes dialog, you'll see a list of schemes and their associated targets.
		- You can either edit an existing scheme to include the new target or create a new scheme.
			- To edit an existing scheme, select it and click 'Edit'. In the scheme editor, you can add the new target to various phases like 'Build', 'Run', 'Test', etc., by using the '+' button in each section.
			- To create a new scheme, click on the '+' button at the bottom left of the window, name your scheme, and select the target you want to associate with this scheme.
- Configure the Scheme:
	- After adding the target, configure the scheme settings according to your requirements. This includes specifying build configurations and other run/debug settings for the target.
	- Save and Close:
		- Click 'OK' to save your changes and close the scheme editor.
- Select the Scheme for Use:
	- Select your newly created or edited scheme from the scheme dropdown menu in the toolbar.
