### Notes
- #### Starting a New Project in KiCad
- A new project in KiCad 9 begins with downloading and installing the software. Running multiple versions of KiCad simultaneously is possible, allowing users to work on projects in different versions if needed. In this case, KiCad 9 is installed alongside KiCad 8, the official stable version at the time of recording.
- Project preparation involves gathering and finalizing the bill of materials (BOM). While the BOM may evolve throughout the design process, major components like microcontrollers and integrated circuits should be selected early. Generic components such as resistors and capacitors can be adjusted later based on design needs. In practice, project preparation includes extensive research using resources like SnapEDA to find and download footprints, symbols, and data sheets. This ensures that essential information is available before schematic design begins. The total time spent on preparation, including reading data sheets and collecting necessary files, is estimated at five to six working hours.
- Source: Lecture 08-080 - Start the Project

#### Configuring a KiCad Project for Optimal Workflow
- Project configuration in KiCad involves setting up the working directory, defining user preferences, and installing necessary plugins. When creating a new project, users can choose whether to generate a new folder or use an existing one. KiCad saves project files in the selected directory, and users must confirm their choice if the folder is not empty.
- Basic setup includes adjusting display options for better visual clarity, such as enabling high-quality anti-aliasing in the schematic editor. Grid settings should be configured for efficient component placement and alignment, with options for different grid sizes and fast-switching intervals. Annotation and editing options are generally left at their default values unless specific changes are required.
- KiCad supports various plugins that enhance design capabilities. Among the recommended plugins are Interactive HTML BOM, which helps visualize the bill of materials in an interactive format, and PCB Action Tools, which provide additional automation features. The FreeRouting plugin is particularly useful for automating PCB routing, while HQDFM is essential for checking design for manufacturability (DFM) before submitting it to a manufacturer. These tools improve workflow efficiency and help detect potential design issues early.
- Source: Lecture 09-090 - Project Configuration

#### Installing and Managing Symbol and Footprint Libraries
- Symbol and footprint libraries are critical for accurate schematic and PCB design in KiCad. Users must decide whether to install these libraries globally for all future projects or specifically for the current project. The project-specific option is preferred when dealing with unique components, as it provides better control and prevents unnecessary clutter in other designs.
- To install footprint libraries, users navigate to the Preferences menu and select the Footprint Libraries Manager. By choosing the project-specific option, they can import a designated folder containing `.kicad_mod` files. The imported library is assigned a recognizable nickname, such as "ESP32 Project Libraries," making it easy to locate when selecting components.
- The process for installing symbol libraries is similar. Symbols are stored in `.lib` files, and users can multi-select all necessary files when importing them into KiCad. Once installed, the symbol and footprint libraries are integrated into the project, allowing seamless component selection in the schematic editor. With these libraries in place, the design process can proceed efficiently without interruptions related to missing component data.
- Source: Lecture 10-100 - Install the Footprint and Symbol Libraries
