## Overview

ThermoX is a thermostatic HVAC control system designed for a gazebo. It uses an ESP32 microcontroller to manage temperature control, integrate with Blynk for remote management, and fetch weather forecasts from OpenWeather.

## Key Features

- Temperature control using a DHT22 sensor
- Integration with Blynk for remote control and monitoring
- Weather forecast fetching from OpenWeather
- OTA (Over-The-Air) updates
- WiFi management with auto-reconnect and access point fallback
- EEPROM storage for settings
- Manual override and voice control via IFTTT / Amazon Echo

## Main Components

### Setup Function

The `setup()` function initializes the system:

1. Establishes serial communication
2. Connects to WiFi
3. Initializes Blynk, Access Point, and OTA update functionality
4. Sets up the fan relay
5. Loads settings from EEPROM
6. Initializes timers and NTP time synchronization
7. Starts the temperature sensor
8. Fetches and prints current weather

### Loop Function

The `loop()` function handles the main program execution:

1. Manages OTA updates
2. Runs Blynk
3. Executes scheduled timer events
4. Listens for Nextion display events

### Key Helper Functions

- `checkWifi()`: Monitors WiFi connection and reboots if disconnected
- `TempUpdate()`: Updates temperature readings
- `TimerStatus()`: Manages timer statuses
- `Fan(boolean)`: Controls the fan relay
- `KillManual()`: Disables manual mode
- `intervals()`: Sets up periodic events
- `getTime()`: Synchronizes time with NTP server
- `printCurrentWeather()`: Fetches and displays current weather data

## Configuration

The system uses various configuration files and libraries:

- `settings.h`: Contains system-wide settings
- `eepromPresets.h`: Manages EEPROM storage of settings
- `thermostat.h`: Defines thermostat functionality
- `blynkModule.h`: Handles Blynk integration
- `timers.h`: Manages system timers
- `ap.h`: Configures the access point
- `ntpServer.h`: Manages NTP time synchronization
- `nh_ota.h`: Handles OTA updates

## Hardware Requirements

- ESP32 microcontroller
- DHT22 temperature and humidity sensor
- Relay for fan control
- Nextion display (optional)

## Note

This system is designed for a specific use case (gazebo heating) and includes various integrations (Blynk, IFTTT, Amazon Echo). Modifications may be necessary for different applications or environments.
