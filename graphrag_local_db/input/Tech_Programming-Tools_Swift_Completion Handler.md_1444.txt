### Notes
-  In Swift, a completion handler is a type of closure that is used to handle the result of an asynchronous task. It allows you to specify a block of code to be executed once a task is finished, enabling your code to continue its execution in the meantime. Completion handlers are particularly useful in scenarios involving network requests, long-running calculations, or any operations that are performed in the background.
