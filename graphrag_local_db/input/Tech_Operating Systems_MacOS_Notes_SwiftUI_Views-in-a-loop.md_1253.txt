### Notes
1.  ForEach creates views in a loop

2.  No 10 view limit

3.  ForEach runs a closure once for every item, passing the current loop item.

    a.  Loops over arrays and ranges

    b.  For example, this creates a form with 100 rows:

Form {

ForEach(0 ..< 100) { number in

Text("Row (number)")

}

}

3.  Because ForEach passes in a closure, we can use shorthand syntax for the parameter name, like this:

Form {

ForEach(0 ..< 100) {

Text("Row ($0)")

}

}
