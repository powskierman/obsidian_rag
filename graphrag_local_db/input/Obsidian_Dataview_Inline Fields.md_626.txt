### Notes
- Inline Fields: For a more natural-looking annotation, Dataview supports "inline" fields, which offer a simple *Key:: Value* syntax that you can embed directly in your file. ex:
	- Basic Field:: Value
	- **Bold Field**:: Nice! 
- Use the bracket syntax to embed metadata inside sentences, or multiple fields on the same line:
	- I would rate this a [rating:: 9]! It was [mood:: acceptable].
