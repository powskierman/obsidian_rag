            1.  Edit env file

                a.  Location found in docker-compose.yml device definition

                b.  Mqtt publisher config in env file

Z=America/Edmonton

MQTT_ADDRESS=mosquitto

MQTT_PORT=1883

#MQTT_USER=""

#MQTT_PASSWORD=""

MQTT_TOPIC=porch[/model][/id]

3.  Delete sensor container

4.  Docker-compose up -d

ii. Edit configuration.yaml in IOTstack directory

sensor:

- platform: mqtt

state_topic: "porch/Acurite-Tower/10798"

name: "Porch temperature"

unit_of_measurement: "°C."

force_update: true

value_template: "{{ value_json.temperature_C }}"

i.  Https

    1.  Install [duckdns](https://www.duckdns.org/domains) addon in Supervisor addon store

        1.  [Instructions](https://help.konnected.io/support/solutions/articles/32000023964-set-up-hass-io-with-secure-remote-access-using-duckdns-and-nginx-proxy)

        2.  Alternatively, [use dehydrated](https://www.splitbrain.org/blog/2017-08/10-homeassistant_duckdns_letsencrypt)

    ```{=html}
    <!-- -->
    ```
    1.  Portforward 8123 in router

    2.  **Not required with nginx**:

        1.  Configuration.yaml entry

http:

ssl_certificate: /config/ssl/certs/powskierman.duckdns.org/fullchain.pem

ssl_key: /config/ssl/certs/powskierman.duckdns.org/privkey.pem

base_url: powskierman.duckdns.org:8123



ii. Create ssl folder with certs and keys in /usr/share/hassio/homeassistant

    1.  Don't forget Home Assistant is running in Docker. Files from this directory will be copied to container.

    2.  To access container: docker exec -it <container ID> /bin/sh
