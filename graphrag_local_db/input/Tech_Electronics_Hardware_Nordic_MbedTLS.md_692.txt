### Notes
-  mbedTLS is the crypto/SSL library that powers much of the security functionality in the nRF52 BLE and Matter solutions.
- Provides cryptographic building blocks like symmetric ciphers, hashes, MACs, asymmetric ciphers, key exchange, and cryptography utilities.
- Implements SSL/TLS capabilities for securing communications with TLS certificates, cipher suites, authentication etc.
- Written in portable C designed for resource constrained devices like microcontrollers.
- Minimal RAM and code footprint - can fit on devices with only tens of kilobytes of memory.
- Licensed under the Apache 2.0 license, so can be used in commercial products.
- Used as the cryptographic and SSL/TLS library in many open source projects like Zephyr, embedded MQTT brokers, and cryptographic frameworks.
- Offered by ARM as a lightweight open source alternative to OpenSSL.
- Modular design so you only need to compile and link in features actually used by your application.
