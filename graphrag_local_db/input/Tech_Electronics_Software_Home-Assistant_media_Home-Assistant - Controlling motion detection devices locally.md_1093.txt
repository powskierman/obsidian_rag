			- [localtuya local handling for Tuya devices](https://github.com/rospogrigio/localtuya)
			- [Absolute beginners guide to setting up Local Tuya for Home Assistant  homeassistant](https://www.reddit.com/r/homeassistant/comments/oglpgc/absolute_beginners_guide_to_setting_up_local_tuya/)
		- [Replaced with localtuya - Tutorial for TuyaMqtt](https://community.openhab.org/t/step-by-step-guide-for-adding-tuya-bulbs-wi-fi-smart-led-smart-life-app-to-oh2-using-tuya-mqtt-js-by-agentk/59371/7
		- [autostart tuya-mqtt](https://pm2.keymetrics.io) with [systemd](https://www.linode.com/docs/guides/start-service-at-boot/)
			- Setup tuya-mqtt as service
			- Place this file in /etc/systemd/system/tuyaapi-mqtt.service
				#!/bin/sh
				[Unit]
				Description=tuyaapi-mqtt
				
				[Service]
				WorkingDirectory=/home/pi/IOTstack/tuya-mqtt
				ExecStart=/usr/bin/node tuya-mqtt.js
				Restart=always
				User=pi
				Group=pi
				Environment=PATH=/usr/bin/
				Environment=NODE_ENV=production
				
				[Install]
				WantedBy=multi-user.target
				Alias=tuyaapi-mqtt.service
		- Control systemd with [systemctl](https://linuxconfig.org/how-to-use-systemctl-to-list-services-on-systemd-linux)
		- Or from within IOTstack/tuya-mqtt
			- [Pm2](https://pm2.keymetrics.io) is a process manager for node.js
			- 
			- pm2 start tuya-mqtt
