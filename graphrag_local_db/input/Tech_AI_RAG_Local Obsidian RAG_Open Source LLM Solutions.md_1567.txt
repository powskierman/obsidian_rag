# Open Source LLM Solutions

> Run powerful language models without API costs or privacy concerns

## Overview

Open source LLM solutions let you run models locally or self-hosted, eliminating per-query costs and keeping data private. Perfect for RAG systems where you need reliable, cost-effective AI processing.

**Key Benefit:** $0 per query after initial hardware investment

---

## Quick Comparison

| Solution | License | Complexity | Best For | API Compatible |
|----------|---------|------------|----------|----------------|
| **Ollama** | MIT | ⭐⭐ Easy | Local deployment | OpenAI-like |
| **LiteLLM** | MIT | ⭐⭐ Easy | Multi-model proxy | OpenAI |
| **LocalAI** | MIT | ⭐⭐⭐ Moderate | OpenAI replacement | OpenAI |
| **vLLM** | Apache 2.0 | ⭐⭐⭐⭐ Complex | High throughput | OpenAI |

## 1. Ollama (RECOMMENDED)

### Overview
- **License:** MIT
- **Best For:** Running models locally with minimal setup
- **Cost:** FREE (hardware only)
- **Website:** https://ollama.com/

### Why Choose Ollama?
✅ Simplest setup (1 command)
✅ 50+ models available
✅ Automatic GPU utilization
✅ CPU fallback works well
✅ Active development
✅ Great community

### Installation

**macOS/Linux:**
```bash
curl -fsSL https://ollama.com/install.sh | sh
```

**Windows:**
Download from https://ollama.com/download

**Docker:**
```bash
docker run -d -v ollama:/root/.ollama -p 11434:11434 --name ollama ollama/ollama
```

### Basic Usage

```bash
# Pull a model
ollama pull llama3.2

# Run interactively
ollama run llama3.2

# Start API server (runs automatically after install)
ollama serve
```

### Available Models

**Recommended for RAG:**

| Model | Size | RAM | Speed | Quality | Best For |
|-------|------|-----|-------|---------|----------|
| **llama3.2:3b** | 2GB | 4GB | ⭐⭐⭐⭐⭐ | ⭐⭐⭐ | Quick responses |
| **llama3.2:7b** | 4GB | 8GB | ⭐⭐⭐⭐ | ⭐⭐⭐⭐ | Balanced |
| **mistral:7b** | 4GB | 8GB | ⭐⭐⭐⭐ | ⭐⭐⭐⭐ | Reasoning |
| **mixtral:8x7b** | 26GB | 32GB | ⭐⭐ | ⭐⭐⭐⭐⭐ | High quality |
| **qwen2.5:7b** | 4GB | 8GB | ⭐⭐⭐⭐ | ⭐⭐⭐⭐ | Multilingual |

**Specialized Models:**
- `codellama:7b` - Code generation
- `deepseek-coder:6.7b` - Advanced coding
- `nomic-embed-text` - Text embeddings (for vector creation)
- `llava:7b` - Vision + language
- `phi3:3.8b` - Microsoft's efficient model

### API Usage

**cURL:**
```bash
curl http://localhost:11434/api/chat -d '{
  "model": "llama3.2",
  "messages": [
    {"role": "user", "content": "What is RAG?"}
  ],
  "stream": false
}'
```

**Python:**
```python
import requests
import json

response = requests.post('http://localhost:11434/api/chat',
    json={
        'model': 'llama3.2',
        'messages': [
            {'role': 'system', 'content': 'You are a helpful assistant.'},
            {'role': 'user', 'content': 'What is RAG?'}
        ],
        'stream': False
    }
)

print(response.json()['message']['content'])
```

### n8n Integration

```javascript
// HTTP Request node
URL: http://localhost:11434/api/chat
Method: POST
Headers: {
    "Content-Type": "application/json"
}
Body: {
    "model": "llama3.2",
    "messages": [
        {
            "role": "system",
            "content": "Use this context: {{ $json.context }}"
        },
        {
            "role": "user",
            "content": "{{ $json.userMessage }}"
        }
    ],
    "stream": false
}
```

### Creating Embeddings

```bash
# Pull embedding model
ollama pull nomic-embed-text

# Generate embedding
curl http://localhost:11434/api/embeddings -d '{
  "model": "nomic-embed-text",
  "prompt": "The sky is blue"
}'
```

### Hardware Requirements

| Model Size | Min RAM | Recommended RAM | GPU VRAM | Speed Improvement |
|------------|---------|-----------------|----------|-------------------|
| **3B** | 4GB | 8GB | 4GB | 5-10x |
| **7B** | 8GB | 16GB | 8GB | 5-10x |
| **13B** | 16GB | 32GB | 12GB | 5-10x |
| **34B** | 32GB | 64GB | 24GB | 5-10x |
| **70B** | 64GB | 128GB | 48GB | 5-10x |

### Performance Tuning

```bash
# Adjust context window
ollama run llama3.2 --ctx-size 8192

# Control GPU layers (for partial GPU offload)
ollama run llama3.2 --gpu-layers 20

# Set number of threads
ollama run llama3.2 --num-thread 8
```

### When to Use Ollama
- ✅ Getting started with local LLMs
- ✅ Privacy-critical applications
- ✅ No internet connection needed
- ✅ Want zero per-query costs
- ✅ Testing multiple models easily

## 2. LiteLLM

### Overview
- **License:** MIT
- **Best For:** Unified API for 100+ LLMs
- **Website:** https://docs.litellm.ai/

### Why Choose LiteLLM?
✅ Single API for all providers
✅ OpenAI-compatible format
✅ Built-in caching
✅ Cost tracking
✅ Load balancing
✅ Fallback support

### Docker Setup

```yaml
# docker-compose.yml
version: '3'
services:
  litellm:
    image: ghcr.io/berriai/litellm:main-latest
    ports:
      - "8000:8000"
    environment:
      - DATABASE_URL=postgresql://litellm:password@postgres:5432/litellm
      - LITELLM_MASTER_KEY=<dummy key>
    volumes:
      - ./config.yaml:/app/config.yaml
    
  postgres:
    image: postgres:15
    environment:
      - POSTGRES_DB=litellm
      - POSTGRES_USER=litellm
      - POSTGRES_PASSWORD=password
```

### Configuration

```yaml
# config.yaml
model_list:
  # Ollama models
  - model_name: ollama/llama3.2
    litellm_params:
      model: ollama/llama3.2
      api_base: http://localhost:11434
  
  # OpenAI
  - model_name: gpt-4o-mini
    litellm_params:
      model: gpt-4o-mini
      api_key: os.environ/OPENAI_API_KEY
  
  # Anthropic Claude
  - model_name: claude-sonnet-4-5
    litellm_params:
      model: claude-sonnet-4-5-20250929
      api_key: os.environ/ANTHROPIC_API_KEY

# Enable features
litellm_settings:
  cache: true
  max_budget: 100.0  # USD
  budget_duration: 30d
```

### Usage

```python
import openai

# Point to LiteLLM instead of OpenAI
openai.api_base = "http://localhost:8000"
openai.api_key = "<dummy key>"  # Your LiteLLM key

response = openai.ChatCompletion.create(
    model="ollama/llama3.2",  # Or any configured model
    messages=[
        {"role": "user", "content": "What is RAG?"}
    ]
)

print(response.choices[0].message.content)
```

### n8n Integration

```javascript
// Use OpenAI node, change base URL
Authentication: Header Auth
Header Name: Authorization
Header Value: Bearer <dummy key>

Base URL: http://localhost:8000
Model: ollama/llama3.2
```

### Cost Tracking

```bash
# View costs
curl http://localhost:8000/spend/logs

# Set budget
curl http://localhost:8000/budget/set \
  -H "Authorization: Bearer <dummy key>" \
  -d '{"max_budget": 100, "budget_duration": "30d"}'
```

### When to Use LiteLLM
- ✅ Need to switch between providers easily
- ✅ Want cost tracking
- ✅ Require fallback mechanisms
- ✅ OpenAI SDK compatibility
- ✅ Load balancing across models

## 3. LocalAI

### Overview
- **License:** MIT
- **Best For:** Drop-in OpenAI replacement
- **Website:** https://localai.io/

### Why Choose LocalAI?
✅ OpenAI API compatible
✅ Supports audio, images, embeddings
✅ No internet after setup
✅ CPU and GPU support
✅ Multiple backends (llama.cpp, whisper, etc.)

### Docker Setup

```bash
# Quick start
docker run -p 8080:8080 \
  -v $PWD/models:/models \
  localai/localai:latest

# With GPU support
docker run --gpus all -p 8080:8080 \
  -v $PWD/models:/models \
  localai/localai:latest-gpu-nvidia
```

### Download Models

```bash
# Create models directory
mkdir models && cd models

# Download llama model
curl -LO https://huggingface.co/TheBloke/Llama-2-7B-Chat-GGUF/resolve/main/llama-2-7b-chat.Q4_K_M.gguf

# Create config
cat > llama-2-7b-chat.yaml <<EOF
name: llama-2-7b-chat
backend: llama-cpp
parameters:
  model: llama-2-7b-chat.Q4_K_M.gguf
  temperature: 0.7
  top_k: 40
  top_p: 0.95
EOF
```

### Usage (OpenAI Compatible)

```python
import openai

openai.api_base = "http://localhost:8080/v1"
openai.api_key = "dummy"  # Not used

response = openai.ChatCompletion.create(
    model="llama-2-7b-chat",
    messages=[
        {"role": "user", "content": "What is RAG?"}
    ]
)

print(response.choices[0].message.content)
```

### Embeddings

```python
# Generate embeddings
response = openai.Embedding.create(
    model="text-embedding-ada-002",  # Or local model
    input="The sky is blue"
)

embedding = response.data[0].embedding
```

### When to Use LocalAI
- ✅ Need OpenAI API compatibility
- ✅ Want audio/image processing
- ✅ Offline operation required
- ✅ Multi-modal applications
- ✅ Existing OpenAI SDK code

## 4. vLLM

### Overview
- **License:** Apache 2.0
- **Best For:** High-throughput production inference
- **Website:** https://docs.vllm.ai/

### Why Choose vLLM?
✅ Extremely fast (PagedAttention)
✅ High throughput
✅ GPU-optimized
✅ OpenAI-compatible API
✅ Supports most HF models

### Installation

```bash
# Via pip (requires CUDA)
pip install vllm

# Docker (recommended)
docker run --gpus all \
  -v ~/.cache/huggingface:/root/.cache/huggingface \
  -p 8000:8000 \
  --ipc=host \
  vllm/vllm-openai:latest \
  --model meta-llama/Llama-2-7b-chat-hf
```

### Server Setup

```bash
# Start vLLM server
python -m vllm.entrypoints.openai.api_server \
  --model meta-llama/Llama-2-7b-chat-hf \
  --port 8000
```

### Usage

```python
import openai

openai.api_base = "http://localhost:8000/v1"
openai.api_key = "dummy"

response = openai.ChatCompletion.create(
    model="meta-llama/Llama-2-7b-chat-hf",
    messages=[
        {"role": "user", "content": "What is RAG?"}
    ]
)
```

### Performance Features

```bash
# Enable tensor parallelism (multi-GPU)
python -m vllm.entrypoints.openai.api_server \
  --model meta-llama/Llama-2-7b-chat-hf \
  --tensor-parallel-size 2

# Set GPU memory utilization
python -m vllm.entrypoints.openai.api_server \
  --model meta-llama/Llama-2-7b-chat-hf \
  --gpu-memory-utilization 0.9
```

### When to Use vLLM
- ✅ High-volume production
- ✅ Have GPU infrastructure
- ✅ Need maximum throughput
- ✅ Serving multiple users
- ✅ Cost-per-query matters

## Cost Analysis

### Scenario: 10,000 queries/day (7B model)

**Commercial API (GPT-4o-mini):**
- Cost per 1M tokens: $0.30
- Average tokens per query: 500
- Daily cost: $1.50
- **Monthly: $45**
- **Annual: $540**

**Self-Hosted with Ollama:**
- Hardware: $1,500 (one-time, RTX 4070 12GB)
- Electricity: ~$10/month
- **Monthly: $10**
- **Annual: $120 + $1,500 = $1,620 first year, $120 after**
- **Break-even: 2.8 years**

**Higher Volume (100,000 queries/day):**
- Commercial: $5,400/year
- Self-hosted: $120/year (after hardware)
- **Break-even: 4 months**

## Model Selection Guide

### By Use Case

**General RAG (Balanced):**
- Ollama: `llama3.2:7b` or `mistral:7b`
- 8GB RAM minimum
- Good quality/speed balance

**High-Volume Production:**
- vLLM: `meta-llama/Llama-2-13b-chat-hf`
- GPU required
- Maximum throughput

**Privacy-Critical:**
- Ollama: Any model locally
- Air-gapped deployment
- Zero data leakage

**Budget-Constrained:**
- Ollama: `llama3.2:3b` or `phi3:3.8b`
- 4GB RAM sufficient
- Acceptable quality

**Multilingual:**
- Ollama: `qwen2.5:7b`
- Excellent non-English support

### By Hardware

**Laptop (8GB RAM, no GPU):**
- Ollama: `llama3.2:3b`
- 5-10 tokens/sec
- Good for development

**Workstation (32GB RAM, RTX 3080):**
- Ollama: `llama3.2:7b` or `mixtral:8x7b`
- 50-80 tokens/sec
- Production-ready for small scale

**Server (128GB RAM, A100 GPU):**
- vLLM: `meta-llama/Llama-2-70b-chat-hf`
- 100+ tokens/sec
- Enterprise-grade

## Integration Patterns

### Pattern 1: Direct Integration
```
n8n → Ollama → Response
```
**Best for:** Simple deployments

### Pattern 2: Load Balancing
```
n8n → LiteLLM → [Ollama | OpenAI | Claude]
```
**Best for:** Reliability with fallbacks

### Pattern 3: Caching Layer
```
n8n → Redis Cache → Ollama → Response
```
**Best for:** Repeated queries

### Pattern 4: Multi-Model
```
n8n → Model Router → [Fast Model | Quality Model]
```
**Best for:** Optimizing cost/quality
