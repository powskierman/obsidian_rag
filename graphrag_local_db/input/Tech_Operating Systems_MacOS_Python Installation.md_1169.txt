### Notes
- -  On MacOS, Python should run in a virtual environment
1. Create a new virtual environment:
    `python3 -m venv <venv>`    
2. Activate the virtual environment:    
    `source <venv>/bin/activate`
3. Install the package within the virtual environment:text
    `pip3 install -U <package>`
