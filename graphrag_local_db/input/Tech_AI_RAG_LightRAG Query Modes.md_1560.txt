### Main Idea

LightRAG provides four query modes optimized for different information retrieval patterns: naive (baseline), local (entity-focused), global (theme-focused), and hybrid (combined).

### Query Modes

**1. Naive Mode**
```python
result = rag.query(question, mode="naive")
```
- Traditional vector search only
- Baseline comparison with current RAG
- Fastest performance
- No graph traversal
- Best for: Simple fact lookups

**2. Local Mode**
```python
result = rag.query(question, mode="local")
```
- Entity-focused search
- Retrieves specific entities and their immediate relationships
- Graph traversal from query entities
- Best for: "What is X?", "Everything about Y", timeline queries

**3. Global Mode**
```python
result = rag.query(question, mode="global")
```
- Concept/theme search
- Clusters related concepts across vault
- Higher-level abstraction
- Best for: "What have I learned about X?", thematic synthesis

**4. Hybrid Mode** ⭐ (Recommended)
```python
result = rag.query(question, mode="hybrid")
```
- Combines graph traversal + vector search
- Best of both worlds
- Optimal for most queries
- Best for: Complex multi-part questions, relationship queries

### Notes

**Mode Selection Strategy:**

| Query Pattern | Best Mode | Example |
|---------------|-----------|---------|
| Simple fact | Naive | "What is CAR-T?" |
| Entity details | Local | "Everything about Yescarta" |
| Timeline | Local | "Treatment progression from R-CHOP to now" |
| Theme synthesis | Global | "What have I learned about immunotherapy?" |
| Relationships | Hybrid | "How does X relate to Y?" |
| Multi-hop | Hybrid | "X side effects → Y levels → Z treatment" |
| Complex | Hybrid | "Treatment decision factors and outcomes" |

**Performance Characteristics:**

```
Mode      Speed    Depth    Use Case
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Naive     Fast     Low      Quick lookups
Local     Medium   Medium   Entity-centric
Global    Slow     High     Thematic research
Hybrid    Medium   High     General purpose ⭐
```
