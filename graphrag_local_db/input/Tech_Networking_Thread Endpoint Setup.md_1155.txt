### Notes
#### Setup Procedure
- setup ESP32-H2 or C6 with the [ot-cli example](https://openthread.io/codelabs/esp-openthread-hardware#3)
- Use Postman  to retrieve thread network credentials 
	- OpenThread/Get Thread Network Credentials
- Manually configure the esp32 to join the network:
	- ```
	dataset networkkey <your_network_key> 
	dataset panid <your_pan_id> 
	dataset commit active 
	ifconfig up 
	thread start
```

-  Use the #Home-Assistant #border-router as #commissioner:
	- Go to web gui: 192.168.0.14:8080
	- Commissioner tab
	- Add Joiner PSKd: J01NER
		- Note:  If commission fails, change PSKd. ex: J01NUS
	- Or use CLI:
```
sudo ot-ctl

commissioner start

commissioner joiner add * J01NME

```
- Then on the #DK or #Dongle:
```
ot factoryreset 

ot ifconfig up

ot joiner start J01NME

ot thread start
```
- To view connected devices, go to #OTBR web page at the OTBR's IP, or Home Assistant, port 8080 under the topology tab
- Using CLI on edge device:
	- ot state
		- Needs to be in disabled state for commissioning
	- Once commissioned, 
		- ot dataset active provides the following information:
```
