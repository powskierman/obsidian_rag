# HassWebSocket
Date: 2023-12-07

### Notes
-  HassWebSocket is a class that manages a WebSocket connection. Here's a breakdown of what it does:
- HassWebSocket is a singleton, as indicated by the shared static constant. This means that only one instance of HassWebSocket exists in your application.
- HassWebSocket has a delegate property, which is a weak reference to an object that conforms to the HassWebSocketDelegate protocol. This delegate is notified of events related to the WebSocket connection.
- The connectionState property tracks the current state of the WebSocket connection.
- The socket property is an instance of WebSocket from the Starscream library, which is used to manage the WebSocket connection.
- The pingInterval property defines the interval at which ping messages are sent to keep the WebSocket connection alive.
- The messageId property is an integer that is incremented and attached to each message sent over the WebSocket to track responses.
- The isAuthenticating and isAuthenticated properties track the authentication status of the WebSocket connection.
- The onConnectionStateChanged and onEventReceived properties are closures that are called when the connection state changes and when a message is received from the WebSocket, respectively.
- The pingTimer property is a Timer that sends ping messages at regular intervals defined by pingInterval.
- The eventMessageHandlers property is an array of handlers that process messages received from the WebSocket.
- The reconnectionInterval property defines the interval at which reconnection attempts are made if the WebSocket connection is lost.
- The isAttemptingReconnect property tracks whether a reconnection attempt is currently being made.
- The messageQueue property is a queue of messages that are waiting to be sent over the WebSocket.
- The completionHandlers property is a dictionary that maps message IDs to closures. These closures are called when a response is received for a message with the corresponding ID.
- The init method initializes the HassWebSocket instance, sets up the WebSocket instance, and sets the HassWebSocket instance as the delegate for the WebSocket instance. It retrieves the WebSocket server URL from a Secrets.plist file and crashes the application if the URL is not valid.
