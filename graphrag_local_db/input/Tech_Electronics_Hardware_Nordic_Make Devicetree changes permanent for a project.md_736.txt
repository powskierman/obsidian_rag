### Notes
-  The menuconfig changes are saved to the .config file in the build directory, which gets erased on a clean build.
- To make the configuration changes permanent for a project, you need to save them to the board's defconfig file. 
- Here are the steps:
1. After making changes in menuconfig, save and exit. This updates `.config`.
2. Copy the `.config` file to your board's defconfig:
```
cp build/zephyr/.config /opt/nordic/ncs/v2.4.0/zephyr/boards/arm/xiao_matter/xiao_matter_defconfig
```

3. Rebuild your project:

```
west build -p auto clean
```

The changes from `.config` will be applied to the defconfig.

4. Commit the updated defconfig file to git.
- Now your menuconfig changes are saved in the defconfig file, which gets included in all builds for that board.
