### Notes
- Git init
	- Initialize new gt repository
- Git add .
	- Add all files in pwd to git
- Needs to be followed with git commit
- Git commit -am "description"
	- Commits changes to git repository
- Git status
	- Present status of git repository
- Git log
	- Lists changes over time to repository
- [[Git revert]] <branch id to restore>
	- Reverts to previous version.
	- Branch ID is in log
- Needs to be followed with git checkout
- Git checkout <branch id>
