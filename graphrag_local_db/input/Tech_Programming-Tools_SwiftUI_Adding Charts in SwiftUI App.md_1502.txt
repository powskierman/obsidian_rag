### Notes
-  Displaying a graph of temperature data for the last 24 hours when you press the "Temp" button in your SwiftUI application is certainly possible, but it involves several steps. Here's a high-level overview of how you can achieve this:

1. Fetching the Data
First, you'll need to fetch the historical temperature data from Home Assistant. Home Assistant provides various ways to access historical data, typically through its REST API or possibly through integrations that store historical data. You would use an endpoint that allows you to query the state history of your temperature sensor entity for the last 24 hours.

2. Preparing the Data
Once you have fetched the data, you'll need to parse it and prepare it for display. This might involve converting timestamps and temperature values into a format suitable for graphing.

3. Displaying the Graph
For displaying the graph in SwiftUI, you have a few options:

Using SwiftUI Shapes and Paths: You can directly use SwiftUI's drawing tools to create a custom graph. This approach gives you full control over the appearance of the graph but requires more work to handle scaling, axis drawing, and data point visualization.
Using a Third-Party Library: There are several Swift packages and libraries designed for displaying charts and graphs, such as Charts or SwiftUICharts. These libraries can simplify the process of rendering the graph but may add external dependencies to your project.
Using Core Plot: Core Plot is a plotting framework for iOS, macOS, and tvOS. It's more complex and customizable than many SwiftUI-native options but can be integrated into SwiftUI views.
