- Copy from one machine to another
    -  
          -  sudo scp -r "oriDir" "user"@"ip":"destDir"
              -  Sudo for root privileges
              -  -r: recursiv  - To copy directory and contents
              -  "oriDir": Directory to be copied
              -  "user": user on destination machine
              -  "ip": : Destination machine ip with colon
              -  "destDir": Destination directory
  - [ssh on QNAP](https://ripcaster.co.uk/using_putty_with_qnap)
