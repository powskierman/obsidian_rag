### Notes
-  Here are the steps to generate merged.hex and zephyr.uf2 output files for a Zephyr RTOS sample app built using VS Code and west:
- In CMakeLists.txt, make sure you are including the Zephyr boilerplate code:
```
cmake_minimum_required(VERSION 3.20.0)
find_package(Zephyr REQUIRED HINTS $ENV{ZEPHYR_BASE})
project(my_app)

target_sources(app PRIVATE src/main.c)
```

 - Below this, add the following lines:
```
set(HEX_FILE merged.hex)
set(UF2_FILE zephyr.uf2)
```
- At the bottom, include the boilerplate to generate the files:
```
include($ENV{ZEPHYR_BASE}/cmake/flash/ signing.cmake)
create_signed_uf2_zephyr_image(${UF2_FILE})
generate_hex(${HEX_FILE})
```
-  Save the changes to CMakeLists.txt and rebuild your app.
-  The console output will show the merged.hex and zephyr.uf2 being generated.
