- ∅ = [empty set](https://en.wikipedia.org/wiki/Empty_set)
	-   ∅ = {}
- N = [natural [[Numbers]]](https://en.wikipedia.org/wiki/Natural_number)
	-   N = { 1, 2, 3, … }
	-   N0 = { 0, 1, 2, 3, … }
- Z = [integers](https://en.wikipedia.org/wiki/Integer)
	-   Z = { …, -1, 0, 1, … }
- Q = [rational [[Numbers]]](https://en.wikipedia.org/wiki/Rational_number)
- R = [real [[Numbers]]](https://en.wikipedia.org/wiki/Real_number)
- C = [complex [[Numbers]]](https://en.wikipedia.org/wiki/Complex_number)
- {} = Curly brackets denote a set or collection see: [[Solution Set]]
- () = round brackets denote a set excluding the extremities: (4,$\infty$) Numbers between 4 and infinity.  Also called closed notation.
	- $(a, b)=\{x \in \mathbb{R} \mid a<x<b\}$
- [] = square brackets denote a set including the extremities: \[4,10] Numbers from 4 to 10 inclusive. Also called open notation.
	- $[a, b]=\{x \in \mathbb{R} \mid a \leq x \leq b\}$
