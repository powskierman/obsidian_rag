### Notes
```mermaid
flowchart TD
    A[Start] --> B(WebSocketManager Initialization)
    B --> C{WebSocket Connected?}
    C -- Yes --> D[Subscribe to Events]
    C -- No --> E[Connect WebSocket]
    E --> F{Connection Successful?}
    F -- Yes --> D
    F -- No --> G[Handle Connection Failure]

    D --> H[Setup WebSocket Events]
    H --> I[Event Received]
    I --> J[Handle WebSocket Event]
    J --> K[Parse Event Data]
    K --> L{Is State Changed Event?}
    L -- Yes --> M[Process State Change]
    L -- No --> N[Ignore Event]
    M --> O[Update UI State]

    P[Handle Entity Action] --> Q{WebSocket Connected?}
    Q -- Yes --> R[Set Entity State]
    Q -- No --> E
    R --> S[Entity State Updated]

    T[Establish Connection If Needed] --> C

```
