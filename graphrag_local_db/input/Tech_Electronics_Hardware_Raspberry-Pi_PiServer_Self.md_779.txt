### Notes
-  Since the property and the parameter sometimes have the same name, self is used to clarify that you are referring to the property of the class, not the parameter of the method.
- Without self, the compiler would assume you are referring to the method parameter, which would not be correct in this context.
- Usage in Initializers:
	- In initializers (init methods), it's common to use self to differentiate between instance properties and initializer parameters, especially when they have the same name.
