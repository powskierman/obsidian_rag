### Notes
-  The key components are:

- `#ifndef CALL_BACK_H_` - This checks if `CALL_BACK_H_` is already defined. If not, the header will be included.
- `#define CALL_BACK_H_` - This defines the symbol `CALL_BACK_H_`. Once defined, the `#ifndef` will evaluate to false on subsequent inclusions.
- `#endif` - Marks the end of the guarded code block.

The main purpose of using include guards is to prevent multiple inclusion of the same header file. When a header file is included multiple times, it can cause errors like redeclaration of types, functions etc.

The include guard wraps the entire header file code in a conditional block that essentially says:

"If this header has not been included yet, include it, otherwise ignore it."

This prevents the code from being included more than once and avoids redeclaration errors.

Some key points about include guards:

- The macro name is conventionally the header filename in all caps with `_H_`appended.
- They should be added at the very top and bottom of every `.h` header file.
- The `#ifndef` and `#define` must use the exact same name for the macro.
- Include guards don't work for `.c` files, only for `.h`.
