### Notes
-  The procedure for installing HACS (Home Assistant Community Store) in Home Assistant OS (Hass OS) is essentially the same as in other Home Assistant installations. However, there are a few nuances to consider with Hass OS:
- Accessing the File System: Hass OS is a bit more closed off than other installations like Home Assistant Supervised or Home Assistant Core. You may need to use the Samba add-on or SSH to access the file system and copy the HACS files to the /config directory.
- Add the Samba share or the SSH & Web Terminal add-on from the Home Assistant Add-on Store. This will allow you to access your Home Assistant file system from another computer on your network.
	- Configure the add-on with a username and password, then start it.
- - Download the latest version of HACS from the HACS GitHub repository.
- Extract the downloaded folder and copy the `hacs` folder to your `/config` directory in Home Assistant.
- Copying the HACS Files:
	- After downloading and extracting the HACS files, copy the hacs folder into your /config directory. You can do this by accessing the Home Assistant file system over the network (using Samba) or via SSH.
- Restart Home Assistant to load the HACS integration.
- Add the HACS integration through the Home Assistant UI and use a GitHub token for authentication.
- After setting up HACS in Home Assistant, restart the system one more time.
