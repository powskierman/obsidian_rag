## System Architecture

### Docker Services
1. **Embedding Service** (Port 8000)
   - Sentence Transformers (`all-MiniLM-L6-v2`)
   - ChromaDB vector database
   - Semantic search capabilities
   - REST API for embedding and querying

2. **LightRAG Service** (Port 8001) - ⚠️ **DEPRECATED**
   - Graph-based RAG with knowledge graphs
   - Entity and relationship extraction
   - **Status:** Deprecated due to event loop conflicts
   - **Replacement:** GraphRAG-Local service (Port 8003)

2b. **GraphRAG-Local Service** (Port 8003) - ✅ **PRODUCTION**
   - Advanced knowledge graph construction with Microsoft GraphRAG
   - Specialized Ollama integration (GraphRAG-Local-Ollama fork)
   - Entity extraction optimized for medical terminology
   - Community detection and hierarchical graph analysis
   - Global and local search capabilities
   - qwen2.5-coder:14b + nomic-embed-text integration

3. **Streamlit UI** (Port 8501)
   - Web interface for queries
   - Model selection and parameters
   - Source citations and relevance scores
   - Export capabilities

4. **Ollama Host** (Port 11434)
   - Local LLM hosting
   - **Primary Model:** qwen2.5-coder:14b (GraphRAG-Local optimized)
   - Qwen 2.5 Coder 32B (traditional RAG)
   - DeepSeek R1:14b (reasoning alternative)

## Quick Start Guide

### Prerequisites
```bash
# Ensure Docker Desktop is running
docker --version
docker-compose --version

# Install Ollama models
ollama pull qwen2.5-coder:14b      # GraphRAG-Local optimized
ollama pull qwen2.5-coder:32b      # Traditional RAG
ollama pull nomic-embed-text       # GraphRAG embeddings
ollama pull deepseek-r1:14b        # Reasoning tasks
```

### Daily Operations
```bash
# Navigate to project
cd "/Users/michel/iCloud Drive/ai/RAG/obsidian_rag"

# Start all services
./Scripts/docker_start.sh

# Access interfaces
open http://localhost:8501    # Main UI
open http://localhost:8000    # Embedding API
open http://localhost:8001    # LightRAG API (deprecated)
open http://localhost:8003    # GraphRAG-Local API ⭐

# Stop services
./Scripts/docker_stop.sh
```

### Indexing Options
```bash
# Option 1: Simple semantic indexing
python simple_scanner.py

# Option 2: Advanced scanner with file watching
python obsidian_scanner.py

# Option 3: GraphRAG-Local indexing (RECOMMENDED) ⭐
./scripts/index_with_graphrag_local.sh
# OR: curl -X POST http://localhost:8003/index-vault

# Option 4: LightRAG graph construction (DEPRECATED)
curl -X POST http://localhost:8001/index-vault

# Option 5: Direct CLI querying
python query_vault.py "your query here"

# Option 6: GraphRAG-Local Docker profile
docker-compose --profile graphrag-local up -d
```

## Service Comparison

| Feature | Embedding Service | LightRAG Service | GraphRAG-Local Service |
|---------|------------------|------------------|----------------------|
| **Port** | 8000 | 8001 | 8003 |
| **Status** | ✅ Production | ⚠️ Deprecated | ✅ **RECOMMENDED** |
| **Search Type** | Semantic similarity | Graph + Semantic | Advanced Knowledge Graph |
| **Best For** | Quick lookups, document similarity | Complex relationships (unstable) | Medical timelines, multi-hop reasoning |
| **Response Speed** | Fast (~1-2 seconds) | Variable (event loop issues) | Moderate (~3-5 seconds) |
| **Context Understanding** | Document-level | Entity aware (buggy) | Community + Entity + Relationship |
| **Setup Complexity** | Simple | Moderate | Moderate |
| **Database** | ChromaDB | LightRAG GraphDB | GraphRAG + Parquet |
| **Ollama Integration** | Basic | Custom implementation | **Native (optimized)** |
| **Medical Optimization** | General embeddings | Limited | **Specialized entity extraction** |

## Docker Architecture Benefits

### Eliminated Issues
- ✅ **Python version conflicts** (isolated containers)
- ✅ **Dependency management** (each service has own environment)
- ✅ **Port conflicts** (Docker Compose orchestration)
- ✅ **NumPy installation issues** (pre-built containers)
- ✅ **Service startup complexity** (single script deployment)

### Production Features
- **Persistent storage** via Docker volumes
- **Service health checks** and automatic restarts
- **Container networking** with service discovery
- **Consistent deployment** across machines
- **Easy backup** (volume snapshots)
