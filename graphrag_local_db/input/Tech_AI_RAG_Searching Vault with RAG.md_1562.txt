#### Three ways to search
1) Claude Desktop (recommended)
	- Your claude_desktop_config_with_obsidian.json registers an obsidian-rag MCP server with these tools:
	- obsidian_simple_search — semantic/vector search
	- obsidian_graph_query — knowledge graph search
	- obsidian_vault_stats — vault statistics
	- How to use it:
	- Open Claude Desktop
	- Ask: "Search my vault for notes about ESP32"
	- Ask: "What does my vault contain about lymphoma?"
	- Ask: "Find my Home Assistant configuration notes"
	- Use the @obsidian_simple_search tool
	- What happens:
	- Vector search runs against ChromaDB on port 8000
	- It finds relevant note chunks
	- Results include citations and relevance scores
	- Claude summarizes the matches

2) Streamlit web UI
	- Open http://localhost:8501
	- Select search mode (vector, graph-, hybrid, etc.)
	- Enter your query and get formatted results
	- Review sources with relevance scores 
	  
   3) Via CLI with Claude Code (detailed)
	- Run ./search_vault 'Home Assistant' 
	- Full content, no truncation
	- Saved to a file
	- For thorough analysis
	- `./search_vault 'ESP32' 20            # Gets top 20`

## Use case examples

- Quick lookup in conversation: MCP in Claude Desktop

- Deep research on a topic: ./search_vault 'your query'

- ESP32 analysis: ./search_vault 'ESP32' 20

- Medical research: ./search_vault 'lymphoma' and review the full file

Choose the approach that fits your workflow.
