		- ot ipaddr

			- Used by device 2 to send to this device
		- ot udp open
		- ot udp bind :: 1234
	- Device 2:
		- ot ipaddr
		- ot udp open
		- Send command with ipv6 address, port and message
			- ot udp send fd5d:e45e:418b:1:582e:7c07:663:3c5d 1234 Hello!
