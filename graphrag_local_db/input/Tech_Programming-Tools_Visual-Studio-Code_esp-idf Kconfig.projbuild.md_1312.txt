### Notes
- This file configures the menuconfig app menus. 
- The kconfig.projbuild file is the top-level Kconfig file that includes all other Kconfig files in an ESP-IDF project. Here are some key things to know about it:
 It is located in the root directory of the ESP-IDF project, along with Makefile, components, main, etc.
 It includes the Kconfig files from ESP-IDF core components using "source" statements. For example:
source "$IDF_PATH/components/freertos/Kconfig"
 It also includes the Kconfig files for any components added to the project, e.g.:
source "components/my_component/Kconfig"
 The "main" function defines the top menu item and pulls in sub-menus for compiler options, serial flasher config, component config, etc.
 There are conditional includes based on the chip target and IDF version to pull in the correct files.
 The menus, configuration options and help text are defined in the included Kconfig files. kconfig.projbuild just ties them together into a single menu tree.
 Running 'make menuconfig' opens this combined menu tree in a user interface for editing the configuration.
 The selections are saved in sdkconfig (legacy) or sdkconfig.json format in the project root.
