### Notes
-  Summary of Climate Preset Implementation:

  1. **Configurable Preset Temperature Numbers**
  (gazebo-thermostat.yaml:367-389):
	    - preset_home_temp: Configurable Home preset (default
	  18°C, range 10-35°C)
	    - preset_away_temp: Configurable Away preset (default
	  15°C, range 5-30°C)
	    - Both restore their values and can be adjusted via
	  Home Assistant UI
  2. **Enhanced Thermostat Modes**
  (gazebo-thermostat.yaml:394-405):
	    - Added "Home Preset" and "Away Preset" modes to the
	  thermostat mode selector
	    - These modes automatically sync the desired
	  temperature with their respective preset values
  3. **Preset Application Buttons**
  (gazebo-thermostat.yaml:250-279):
	    - Apply Home Preset button: Sets desired temp to home
	  preset and switches to "Home Preset" mode
	    - Apply Away Preset button: Sets desired temp to away
	  preset and switches to "Away Preset" mode
  4. **Automatic Preset Synchronization**
  (gazebo-thermostat.yaml:603-618):
	    - When in preset modes, the thermostat automatically
	  syncs the desired temperature with the preset values
	    - Prevents manual temperature changes from breaking
	  preset mode functionality
  5. **Nextion Display Integration**
  (gazebo-thermostat.yaml:235-264, 688-702):
	    - Added touch buttons for Home and Away presets on the
	   Nextion display
	    - Display shows current preset values and active
	  preset status
	    - Shows "HOME (18.0°C)" or "AWAY (15.0°C)" when preset
	   modes are active
  6. **Updated Climate Component Reference**
  (gazebo-thermostat.yaml:559-561):
	    - Modified the commented climate component to use
	  configurable preset values instead of hardcoded
	  temperatures

  The implementation replaces all hardcoded preset
  temperatures (18°C Home, 15°C Away) with fully
  configurable number inputs that can be adjusted through
  Home Assistant or the Nextion display. Users can now
  customize their preset temperatures and easily switch
  between them using buttons or mode selection.
