### Notes
-  Delete the Smart Connections cache directory located at the root of the vault before starting Obsidian. The cache directory is at `<location of your vault>/.smart-env.`
- If that does not help you could remove the Smart Connection plugin the _hard_ way and manually delete the plugin directory before you start Obsidian. The plugin directory is at: `<location of your vault>/.obsidian/plugins/smart-connections` .
- If you do that you need to re-install and configure the plugin again from scratch. 
- You should also make sure you use the BGE-micro-v2 embedding model initially.
