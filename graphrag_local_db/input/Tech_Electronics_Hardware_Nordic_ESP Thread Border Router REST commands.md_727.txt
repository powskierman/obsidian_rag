### Notes
#### list of available REST API commands for the ESP Thread Border Router:
Node Information:
`GET http://192.168.0.220:80/node`
Available Networks:
`GET http://192.168.0.220:80/available_network`
Get Properties:
`GET http://192.168.0.220:80/get_properties`
Node Information (alternative endpoint):
`GET http://192.168.0.220:80/node_information`
Topology:
`GET http://192.168.0.220:80/topology`
Join Network (POST request):
POST http://192.168.0.220:80/join_network
Form Network (POST request):
POST http://192.168.0.220:80/form_network
Add Prefix (POST request):
POST http://192.168.0.220:80/add_prefix
Delete Prefix (POST request):
POST http://192.168.0.220:80/delete_prefix
