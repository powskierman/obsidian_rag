### Notes
-  Pass a variable name as a function parameter by using pointers.

```
void myFunction(int\* myVariable) 
	{
	// do something with myVariable 
	} 
int myValue = 10; 
myFunction(&myValue); // pass the memory address of myValue to the function
```
- In this example, the `myFunction` takes a pointer to an integer as a parameter. 
- When calling the function, we pass the memory address of the `myValue` variable using the `&` operator.
- Inside the function, we can access the value of `myValue` by dereferencing the pointer using the `*` operator:
```
void myFunction(int* myVariable) {
  int value = *myVariable; // get the value of the variable pointed to by myVariable
  // do something with value
}

```
Using pointers in this way allows you to pass a variable name as a function parameter, and manipulate its value within the function.
