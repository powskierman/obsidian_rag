### Notes
- OTBR Install:
- Its much less error prone to install via MacOS:
	- [[nrf52840 dongle Openthread RCP]]
	- Install a new RPI3 minimum using raspberry pi imager
	- Install the ARM GCC toolchain
		- `sudo apt install gcc-arm-none-eabi`
	- [Thread Border Router - Bidirectional IPv6 Connectivity and DNS-Based Service Discovery    OpenThread](https://openthread.io/codelabs/openthread-border-router#1)
	- Follow step 4 of:
		- [Build a Thread network with nRF52840 boards and OpenThread](https://openthread.io/codelabs/openthread-hardware#3)
	- Install NRFUtil:
		- `sudo apt update` 
		- `sudo apt install python3 python3-pip`
		- `pip3 install nrfutil`
		- `echo 'export PATH=$PATH:/home/mlapoint99/.local/bin' >> ~/.bashrc`
		- `source ~/.bashrc`
		- `which nrfutil`
	- [Configuring OpenThread Radio Co-processor on nRF52840 Dongle — Matter documentation](https://developer.nordicsemi.com/nRF_Connect_SDK/doc/1.9.99-dev1/matter/openthread_rcp_nrf_dongle.html)
		- If there is an AttributeError, this is the problem:
			- The current release of nRF Util doesn't support Python 3.9. I guess future releases will, but in the meantime you must either use the prebuilt executables available in the release or stick to Python 3.8.
			- Install Python 3.8 with pyenv
- Home Assistant Installation:
	- Use Openthread Border Router Addon in Home Assistant
	- Enable disabled ports at the bottom
	- In thread integration, Reset otbr and choose as home assistant preferred network
	- access via home assistant url, port 8080
	- Add Matter addon
	- Add Matter integration
- On Debian: 
- Border router setup using CLI:
```
sudo ot-ctl 
dataset init new 
dataset channel 15
dataset channelmask 0x7fff800
dataset panid 0xa3aa
dataset extpanid 7817b9fc0d55dfb3 
dataset networkkey <dummy key> 
dataset meshlocalprefix fd00:0000:fb01:0001::
dataset networkname NH
dataset commit active 
ifconfig up 
thread start
prefix add fd11:22::/64 pasor 
netdata register
```
