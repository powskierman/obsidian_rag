The Serial Peripheral Interface (SPI) bus is a synchronous serial bus that offers improved performance compared with I2C. SPI is a four-wire bus with multiple Chip Select lines, which allow it to communicate with more than one target device. The Pi’s SPI bus is available on Pins 19, 21, and 23, with a pair of Chip Select lines on Pin 24 and Pin 26. Pin 19 provides the SPI Master Output, Slave Input (MOSI) signal; Pin 21 provides the SPI Master Input, Slave Output (MISO) signal; Pin 23 provides the Serial Clock (SLCK) used to synchronise communication; and Pins 24 and 26 provide the Chip Select signals for up to two independent slave devices. ([4055](https://readwise.io/to_kindle?action=open&asin=B01K5WSIPQ&location=4055)) %% Color: yellow %% ^334462565
