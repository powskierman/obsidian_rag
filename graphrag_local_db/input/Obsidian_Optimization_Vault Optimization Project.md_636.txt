## Optimization Goals

1. **Standardization**: Consistent frontmatter, naming, and structure
2. **Discoverability**: Better linking, tags, and MoC coverage  
3. **Maintenance**: Identify outdated, duplicate, or low-value notes
4. **Organization**: Optimal folder structure and MoC hierarchy
5. **Automation**: Create systems to maintain organization going forward

**Priority**: High | **Effort**: High

- [ ] Define naming standards for each category:

- [ ] Apply naming convention vault-wide
- [ ] Document the convention for future reference

- [ ] Standardize date formats

**Useful Query Examples** (reference only - remove triple backticks to use):

*Find notes without frontmatter:*
```
TABLE created, tags
WHERE !file.frontmatter
SORT file.name
```

*Find orphaned notes (no backlinks):*
```
TABLE file.outlinks as "Links Out", file.inlinks as "Backlinks"
WHERE length(file.inlinks) = 0
SORT file.name
```
