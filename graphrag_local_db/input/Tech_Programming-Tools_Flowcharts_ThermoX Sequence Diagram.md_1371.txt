sequenceDiagram
    participant User
    participant System

    User->>System: User triggers temperature update via Blynk or manual command.
    System->>System: setup() function is initiated on boot to connect to Wi-Fi and load settings.
    System->>System: loop() begins and handles Blynk.run() to check for incoming commands.
    System->>System: If temperature changes, Fan() function is called accordingly.
    System->>System: If needed, printCurrentWeather is called to retrieve forecasts from OpenWeather.
    User->>System: User receives feedback through the Blynk app as needed.
    User-->>System: Receive feedback
