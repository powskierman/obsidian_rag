### Main Idea

Enhanced RAG architecture combining knowledge graphs with traditional vector search for superior multi-hop reasoning and relationship understanding.

### Architecture Diagram

```
User Query
    ↓
┌───────────────────────────────────┐
│   LightRAG Layer (NEW)            │
│   1. Extract entities/concepts    │
│   2. Query knowledge graph        │
│   3. Get connected subgraph       │
└───────────────────────────────────┘
    ↓
┌───────────────────────────────────┐
│   Traditional RAG Layer           │
│   1. Vector search (ChromaDB)     │
│   2. Re-ranking                   │
│   3. Memory integration (Mem0)    │
└───────────────────────────────────┘
    ↓
┌───────────────────────────────────┐
│   LLM Synthesis                   │
│   Graph context + Chunks → Answer │
└───────────────────────────────────┘
```

### Hybrid Approach Benefits

✅ **Graph traversal** for relationships and connections  
✅ **Vector search** for semantic similarity  
✅ **Memory integration** for personal context  
✅ **LLM synthesis** for natural language generation

### Notes

**Component Integration:**

1. **LightRAG Layer**: Builds and queries knowledge graph
   - Extracts entities from markdown content
   - Creates relationship edges between entities
   - Clusters concepts into themes
   - Returns connected subgraphs for queries

2. **Traditional RAG Layer**: Existing Obsidian RAG system
   - SentenceTransformers (all-MiniLM-L6-v2) for embeddings
   - ChromaDB for vector storage
   - Flask API on port 8000
   - Processes 1,584+ markdown files

3. **Smart Query Router**:
```python
def smart_query(question):
    """Route to best system based on query type"""
    
    if is_relationship_query(question):
        # "How does X relate to Y?"
        return lightrag.query(question, mode="hybrid")
    
    elif is_timeline_query(question):
        # "What happened between X and Y?"
        return lightrag.query(question, mode="local")
    
    elif is_simple_lookup(question):
        # "What is X?"
        return current_rag.query(question)
    
    else:
        # Complex: use both!
        graph_context = lightrag.query(question)
        vector_context = current_rag.query(question)
        return synthesize(graph_context, vector_context)
```
