### Notes
-  Use vscode with nrf connect sdk
	- Click on nrf Connect logo in left sidebar
		- Create New Application
		- Freestanding
		- nrf Connect logo in left sidebar
		- Build
			- No build configuration.  Click...
			- Pick board
			- Build Configuration
		- or build CLI:
			- west build -b nrf52840dk_nrf52840 -d build -- -DCONF_FILE=prj.conf -DCMAKE_C_FLAGS=-Os
		- Flash
			- [[Use nrf52840 DK as J-link Programmer]] for Dongle
- Set thread credentials on OTBR
	- Use Edge and postman webapp
		- Connect to 192.168.0.17:5580/ws
		- send:
```
{
    "message_id": "1",
    "command": "set_thread_dataset",
    "args":{
        "dataset": "0e080000000000010000000300000f35060004001fffe002080fb51bb1791e19d50708fdd34f5a1b648b0805109ecd03c14316b8dc93c9f6779e97ca8f030e686f6d652d617373697374616e740102f8ce0410079be2fef6714fd435f9c5511eb967e00c0402a0f7f8"

}
```
				- Send:
```
{
    "message_id": "2",

  }
```
