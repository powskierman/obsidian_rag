### Main Idea
- Complete skill package for systematically reorganizing an Obsidian vault using MCP tools
- 5-phase workflow: Analysis → Cleanup → Frontmatter → Backlinks → Organization
- Leverages batch operations, semantic search, and JsonLogic queries for efficiency
- Safe, interactive process with checkpoints and rollback capabilities

### Quick Start

**Before You Begin:**
- [ ] Backup your vault completely
- [ ] Test MCP connection: `obsidian_list_files_in_vault()`
- [ ] Define your frontmatter template
- [ ] Estimate time based on vault size

**Time Estimates:**

| Vault Size | Total Time |
|-----------|-----------|
| <100 notes | ~45 minutes |
| 100-500 notes | ~2 hours |
| 500-1000 notes | ~4 hours |
| 1000+ notes | ~8 hours |

### The 5 Phases

**Phase 1: Vault Analysis**
- Get vault statistics
- List all files
- Batch analyze notes (10-20 at a time)
- Identify empty notes, missing frontmatter, orphaned notes

**Phase 2: Empty Note Cleanup**
- Review empty notes (< 20 characters)
- Delete with user confirmation
- Log all deletions for rollback

**Phase 3: Frontmatter Standardization**
- Add frontmatter to notes without
- Extract inline tags and categories
- Update existing frontmatter fields
- Use `obsidian_patch_content` for safe updates

**Phase 4: Backlink Identification**
- Find orphaned notes (zero backlinks)
- Use semantic search (RAG) to find related notes
- Rank suggestions by relevance
- Add backlinks to frontmatter

**Phase 5: Categorical Organization**
- Analyze all categories and tags
- Design folder structure
- Move files to appropriate folders
- Update wikilinks if needed
- Verify link integrity

### Key MCP Tools Used

**Most Important:**
- `obsidian_batch_get_file_contents()` - Read 10-20 files at once
- `obsidian_complex_search()` - Find notes by metadata (JsonLogic)
- `obsidian_simple_search()` - Semantic search for backlinks (RAG)
- `obsidian_patch_content()` - Add/update frontmatter safely
- `obsidian_graph_query()` - Find orphaned notes

**Supporting:**
- `obsidian_vault_stats()` - Vault overview
- `obsidian_list_files_in_vault()` - File inventory
- `obsidian_delete_file()` - Remove empty notes
- `obsidian_get_recent_changes()` - Recent activity
