- Adding a Custom MCP Server (Not in Docker MCP Catalog)

This guide outlines step-by-step instructions to add and run a custom MCP server (e.g., Claude Text Editor MCP) using Docker Compose, when the server is not available in the Docker MCP Toolkit catalog.

​
1. Obtain the MCP Server Source

Clone the repository for the MCP server:

shell
git clone https://github.com/tumf/mcp-text-editor.git ~/Documents/MCP_Servers/mcp-text-editor

Check the directory contents to ensure it includes a valid Dockerfile:

shell
ls ~/Documents/MCP_Servers/mcp-text-editor

2. Edit the docker-compose.yml File

Update or create your docker-compose.yml (typically located in your home directory):

text
services:
  mcp-text-editor:
    build: ./Documents/MCP_Servers/mcp-text-editor
    container_name: mcp-text-editor
    ports:
      - "7788:7788"
    restart: unless-stopped

    The build: path must be relative to where you execute docker compose.

    The port (7788) should match the MCP server configuration.

3. Build and Launch the Container

From the directory containing your docker-compose.yml, run:

shell
docker compose up --build -d

If you get a container name conflict, remove the existing instance:

shell
docker stop mcp-text-editor
docker rm mcp-text-editor

Then re-run:

shell
docker compose up --build -d

4. Verify Container Status

List running containers to confirm the MCP server is active:

shell
docker ps

5. Update Your Claude Configuration

Add an entry for the MCP server endpoint in your Claude client config (e.g., claude.json):

json
{
  "mcpServers": {
    "docker-gateway": {
      "command": "docker",
      "args": ["mcp", "gateway", "run"]
    },
    "text-editor-mcp": {
      "url": "http://localhost:7788"
    }
  }
}

Restart Claude Desktop or your client app for the changes to take effect.
6. Troubleshooting

    If Docker Compose cannot locate the Dockerfile, check your build: path.

    Always run Docker Compose commands in the directory containing your docker-compose.yml.

    Review server logs for issues:

    shell
    docker logs mcp-text-editor

Sample Docker Compose Service Block

text
services:
  mcp-text-editor:
    build: ./Documents/MCP_Servers/mcp-text-editor
    container_name: mcp-text-editor
    ports:
      - "7788:7788"
    restart: unless-stopped

This procedure allows you to run any custom MCP server as a Docker service, even when it's not listed in the Docker MCP Toolkit catalog.
