### Notes
-  To transfer properties between views, we need @State and @Binding
	- Declare and initialize the variable in the top view:
```
struct TabViewTabItems: View{

    @State var selectedHomeIndex = 0

    @State var selectedRoomIndex = 0
```
- In the body, where the receiving View is called, enter the variables as parameters with a 2 way Binding ($)
```
    var body: some View {

        TabView {

            GarageView(selectedHomeIndex: $selectedHomeIndex, selectedRoomIndex: $selectedRoomIndex)
```
