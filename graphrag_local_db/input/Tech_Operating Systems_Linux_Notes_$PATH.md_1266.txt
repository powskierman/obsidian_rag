### Notes
-  1.  `echo $PATH`: This command displays the current value of the PATH variable.
    
2.  `export PATH=$PATH:/path/to/directory`: This command adds a new directory to the PATH variable.
    
3.  `unset PATH`: This command removes the PATH variable from the environment.
    
4.  `export PATH=$PATH:/usr/local/bin`: This command adds the `/usr/local/bin` directory to the PATH variable. This directory is typically used for locally-installed executables.
    

It's worth noting that changes to the PATH variable are usually made in the `.bashrc` or `.bash_profile` file in the user's home directory. These files are used to set up the environment for the bash shell when it is started.
