### Notes
-  In ESP-IDF, the main logging functionality is provided by the logging library under `esp_log.h`. 

Some key features:

- Defines logging macros like `ESP_LOGE`, `ESP_LOGW`, `ESP_LOGI` etc. These correspond to error, warning, info etc.

- Logging can be configured at runtime using `esp_log_level_set()` to set the log level.

- Uses `ESP_LOG_LEVEL` defines like `ESP_LOG_ERROR`, `ESP_LOG_WARN` etc to represent log levels.

- Log messages can be tagged with modules like `ESP_LOGE("TAG", ...)` 

- Log output goes to UART by default, can be routed to host via JTAG

- Logging can be disabled entirely using `CONFIG_LOG_DEFAULT_LEVEL_NONE`

- Log levels can be overridden for specific modules

Some examples:

```c
ESP_LOGE("main", "Failed to initialize SPI bus"); // Error log

ESP_LOGW("wifi", "WiFi disconnected"); // Warning log 

ESP_LOGI("app_main", "Starting application"); // Info log
```

So in summary, esp_log.h provides logging features like log levels, modules, runtime configuration etc. This is the recommended way to do logging in ESP-IDF based programs.
