### Notes
| **Keystroke**          | **Action**                  |
|------------------------|-----------------------------|
| Ctrl+Alt+T             | Terminate the session       |
| Ctrl+Alt+F             | Toggle the fullscreen       |
| Ctrl+Alt+I             | Identify monitors           |
| Ctrl+Alt+<Monitor ID> | Change the current monitor  |
| Ctrl+Alt+A             | View all monitors           |
| Ctrl+alt+0             | Use hot-key for menu access |
| Ctrl+alt+Left-Click    | Release Pointer             |
