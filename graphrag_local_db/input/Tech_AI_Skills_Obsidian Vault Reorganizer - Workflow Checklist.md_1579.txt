## Pre-Flight Checklist

- [x] **Backup vault** - Create full backup before starting
- [ ] **Close Obsidian** - Ensure no files are locked
- [ ] **MCP connected** - Verify Obsidian MCP server is running
- [ ] **Test environment** - Consider testing on a small vault first
- [ ] **Review workflow** - Read [[Obsidian Vault Reorganizer - Complete Workflow]]
- [ ] **Define template** - Prepare new note frontmatter template
- [ ] **Define folder structure** - Plan out category-to-folder mappings

## Phase 2: Empty Note Cleanup

### 2.1 Review Empty Notes
- [ ] Review list of empty notes
- [ ] Preview each empty note (first 100 chars)
- [ ] Decide deletion strategy:
  - [ ] Delete all empty notes
  - [ ] Review each individually
  - [ ] Skip cleanup

### 2.2 Execute Deletions
- [ ] For each empty note to delete:
  - [ ] Preview content one last time
  - [ ] Confirm deletion
  - [ ] Run `obsidian_delete_file(confirm=True)`
  - [ ] Log deletion with timestamp

### 2.3 Verify Cleanup
- [ ] Count remaining files
- [ ] Verify deleted count matches
- [ ] Save deletion log
- [ ] Update working inventory

### Cleanup Complete
- [ ] **Files deleted:** ______
- [ ] **Deletion log saved:** ______
- [ ] **Inventory updated**

## Phase 3: Frontmatter Standardization

### 3.1 Define Frontmatter Template
- [ ] Create standard frontmatter template
- [ ] Define required fields:
  - [ ] title
  - [ ] created
  - [ ] modified
  - [ ] tags
  - [ ] categories
  - [ ] backlinks (if needed)
- [ ] Test template on one note

### 3.2 Process Notes Without Frontmatter
For each note without frontmatter:
- [ ] Read full content with `obsidian_get_file_contents()`
- [ ] Extract inline tags (#tag format)
- [ ] Infer categories from content
- [ ] Generate title from filename
- [ ] Set creation/modification dates

### 3.3 Add Frontmatter
Process in batches of 10:
- [ ] Batch 1 (files 1-10)
  - [ ] Generate frontmatter for each
  - [ ] Review generated frontmatter
  - [ ] Apply with `obsidian_patch_content()`
  - [ ] Verify frontmatter added
- [ ] Batch 2 (files 11-20)
  - [ ] (repeat steps)
- [ ] Batch 3... (continue as needed)

### 3.4 Update Existing Frontmatter
- [ ] Identify notes with incomplete frontmatter
- [ ] Add missing required fields
- [ ] Standardize field names
- [ ] Verify consistency

### Frontmatter Complete
- [ ] **Notes processed:** ______
- [ ] **Errors encountered:** ______
- [ ] **All notes have frontmatter**

## Phase 4: Backlink Identification & Addition

### 4.1 Process Orphaned Notes
For each orphaned note:
- [ ] Read note content
- [ ] Extract key concepts (title + first paragraph)
- [ ] Remove stopwords
- [ ] Identify top 5 keywords

### 4.2 Find Related Notes
- [ ] Run `obsidian_simple_search()` with key concepts
- [ ] Review top 10 results
- [ ] Rank by relevance score
- [ ] Select 3-5 best backlink candidates

### 4.3 Add Backlinks to Frontmatter
For each orphaned note:
- [ ] Select appropriate backlinks (3-5 notes)
- [ ] Format as `[[Note Title]]`
- [ ] Add to frontmatter with `obsidian_patch_content()`
- [ ] Verify backlinks added correctly

### 4.4 Optional: Create Bidirectional Links
- [ ] Identify appropriate placement in related notes
- [ ] Add "See also" or "Related" sections
- [ ] Insert reciprocal links
- [ ] Verify bidirectional connections

### Backlink Complete
- [ ] **Orphans processed:** ______
- [ ] **Backlinks added:** ______
- [ ] **Notes still orphaned:** ______
- [ ] **Graph query shows improvement**

- [ ] Build category frequency map

- [ ] Identify minor categories: ______
- [ ] Create category hierarchy

### 5.2 Design Folder Structure
- [ ] Map categories to folders
- [ ] Define folder hierarchy:
  ```
  /_____________/
    /_____________/
    /_____________/
  /_____________/
    /_____________/
  ```
- [ ] Get user approval for structure
- [ ] Document category → folder mappings

### 5.3 Create Folders
- [ ] Create each folder in hierarchy
- [ ] Verify folders created
- [ ] Set folder metadata (if using)

### 5.4 Map Notes to Folders
For each note:
- [ ] Identify primary category
- [ ] Map to target folder

Move in batches of 20:
- [ ] Batch 1 - Move files

  - [ ] Execute moves

- [ ] Find all wikilinks with `obsidian_complex_search()`

## Rollback Procedure (If Needed)

If something goes wrong:
- [ ] **Stop immediately** - Don't continue with errors
- [ ] **Check backup** - Verify backup is intact
- [ ] **Review logs** - Check operation logs for details
- [ ] **Restore backup** - If needed, restore from backup
- [ ] **Identify issue** - Determine what went wrong
- [ ] **Fix and retry** - Address issue and retry from checkpoint
