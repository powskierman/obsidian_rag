### Notes
- List USB ports: 
```
ls /dev/cu*
``` 
- **Important!** The ESP32 will persist changes such as network credentials, ACLs or NOCs on the flash.  Erase with esptool with Matter and when in doubt.
- Normally, reflashing with new firmware erases the flash completely.  Otherwise:
- esptool.py --chip esp32s3 --port /dev/cu.usbmodem4401  erase_flash
	- If this doesn't work, use web tool:
		- Use Chrome or Edge
		- Go to: https://espressif.github.io/esptool-js/
			- Click connect and choose appropriate USB port
			- Click format
				- **Important!**:  esp32s3 memory start position is 0
				- Need to flash this file then erase flash
					- ~/esp/bootloader/bootloader.bin
