### Notes
-  error "CONFIG_UART_INTERRUPT_DRIVEN must be set for CDC ACM driver"
- This build error indicates that the configuration option `CONFIG_UART_INTERRUPT_DRIVEN` is not set for the CDC ACM driver in the Zephyr configuration. To resolve this issue, enable the `CONFIG_UART_INTERRUPT_DRIVEN` option in your Zephyr configuration.
	- Open this file in a text editor: `prj.conf` or `prj_<board>.conf` . 
	- Add this line:
		- CONFIG_UART_INTERRUPT_DRIVEN=y
- Compile:
```
west build -b nrf52840dongle_nrf52840 -d build -- -DCONF_FILE=prj_no_dfu.conf -DCMAKE_C_FLAGS=-Os	
```
