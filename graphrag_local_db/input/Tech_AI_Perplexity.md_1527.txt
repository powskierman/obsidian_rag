### Notes
- Perplexity AI acts as an extremely powerful search engine, scouring the internet to give real-time answers to user queries
- It combines AI with web search to produce ready-made answers, citing its sources, which are real but tend not to be scholarly.
- It's an integrator, using ChatGPT4, Claude.ai and Code Llama2 amongst others
- Pro is $20/month and offers:
	- Use Copilot for more comprehensive answers (300+ per day)
	- Unlimited File Upload
	- Powerful AI Models
	- Upgrade to Claude-2 or GPT-4 for more accurate answers
