### Notes
To run the Nextion Editor on UTM, which is a virtual machine application for macOS, follow these step-by-step instructions:

1. [[Install UTM and Windows 11]]:
2. Install Nextion Editor:
	- Once Windows 11 is running in UTM, open a web browser and navigate to the official Nextion website to download the Nextion Editor.
	- Install the Nextion Editor on your Windows 11 virtual machine by following the installation prompts.
