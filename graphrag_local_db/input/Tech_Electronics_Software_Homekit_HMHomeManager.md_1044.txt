### Notes
-  HMHomeManager is a class in the HomeKit framework of the iOS SDK. It provides a high-level interface for managing the user's home configuration and accessing the homes and accessories that are available in the HomeKit ecosystem.
- You start by creating a HMHomeManager instance. 
	- This object is responsible for managing the user's home configuration, including discovering and pairing with new accessories, and providing access to the homes and accessories that are available.
