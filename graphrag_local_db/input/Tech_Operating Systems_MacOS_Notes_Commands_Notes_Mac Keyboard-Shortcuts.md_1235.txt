**Option key shortcuts** in macOS:

| **Action**                                 | **Shortcut**                    | **Description**                                                                                                                                                                                                                                                                            |
| ------------------------------------------ | ------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Adjust display brightness in smaller steps | Option–Shift–Brightness Up/Down | Fine-tune the display brightness in smaller increments[<br><br>1<br><br>](https://support.apple.com/en-ca/102650).                                                                                                                                                                         |
| Open Downloads folder                      | Option–Command–L                | Opens the Downloads folder in Finder[<br><br>1<br><br>](https://support.apple.com/en-ca/102650).                                                                                                                                                                                           |
| Hide or show the Dock                      | Option–Command–D                | Toggles the visibility of the Dock[<br><br>1<br><br>](https://support.apple.com/en-ca/102650)[<br><br>2<br><br>](https://hr.ubc.ca/sites/default/files/wp-content/blogs.dir/39/files/Keyboard-Shortcuts-MAC.pdf).                                                                          |
| Hide all other apps                        | Option–Command–H                | Hides all other running applications except the front one[<br><br>1<br><br>](https://support.apple.com/en-ca/102650).                                                                                                                                                                      |
| Close all windows                          | Option–Command–W                | Closes all windows of the current app[<br><br>1<br><br>](https://support.apple.com/en-ca/102650).                                                                                                                                                                                          |
| Force quit an app                          | Option–Command–Escape           | Opens the Force Quit Applications window to close unresponsive apps[<br><br>2<br><br>](https://hr.ubc.ca/sites/default/files/wp-content/blogs.dir/39/files/Keyboard-Shortcuts-MAC.pdf)[<br><br>3<br><br>](https://support.apple.com/en-sg/guide/mac-help/mchld6b9e240/mac).                |
| Move to search field                       | Option–Command–F                | Moves the cursor to the search field in Finder or other apps[<br><br>2<br><br>](https://hr.ubc.ca/sites/default/files/wp-content/blogs.dir/39/files/Keyboard-Shortcuts-MAC.pdf).                                                                                                           |
| Hide or show the path bar                  | Option–Command–P                | Toggles the display of the path bar in Finder windows[<br><br>1<br><br>](https://support.apple.com/en-ca/102650).                                                                                                                                                                          |
| Hide or show the Sidebar                   | Option–Command–S                | Toggles the visibility of the Sidebar in Finder windows[<br><br>1<br><br>](https://support.apple.com/en-ca/102650).                                                                                                                                                                        |
| Copy style                                 | Option–Command–C                | Copies the style of selected text (e.g., font, size) to apply elsewhere[<br><br>2<br><br>](https://hr.ubc.ca/sites/default/files/wp-content/blogs.dir/39/files/Keyboard-Shortcuts-MAC.pdf).                                                                                                |
| Display inspector window                   | Option–Command–I                | Opens an inspector window for detailed information about selected items[<br><br>2<br><br>](https://hr.ubc.ca/sites/default/files/wp-content/blogs.dir/39/files/Keyboard-Shortcuts-MAC.pdf).                                                                                                |
| Minimize all windows                       | Option–Command–M                | Minimizes all windows of the front app to the Dock[<br><br>2<br><br>](https://hr.ubc.ca/sites/default/files/wp-content/blogs.dir/39/files/Keyboard-Shortcuts-MAC.pdf)[<br><br>4<br><br>](https://www.computerworld.com/article/1630407/30-keyboard-shortcuts-mac-users-need-to-know.html). |
| Open System Preferences for Displays       | Option + Brightness Up/Down     | Opens the Displays preferences pane directly from any app[<br><br>4<br><br>](https://www.computerworld.com/article/1630407/30-keyboard-shortcuts-mac-users-need-to-know.html).                                                                                                             |
