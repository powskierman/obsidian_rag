### Notes
-  @Published allows us to create observable objects that automatically announce when changes occur. SwiftUI will automatically monitor for such changes, and re-invoke the `body` property of any views that rely on the data.
- Whenever an object with a property marked `@Published` is changed, all views using that object will be reloaded to reflect those changes.
