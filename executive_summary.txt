OBSIDIAN RAG PROJECT - EXECUTIVE SUMMARY

1. MAIN ENTRY POINTS (What Users Actually Run)
================================================================================

RECOMMENDED PATHS (in order of common use):

A. DOCKER PATH (Simplest - Recommended for Most Users):
   ./Scripts/docker_start.sh          → Start all services
   http://localhost:8501              → Access web UI
   Click "Index Vault" button          → Index your notes
   ./Scripts/docker_stop.sh            → Stop all services

B. KNOWLEDGE GRAPH BUILDING (Best Quality - Uses Claude):
   export ANTHROPIC_API_KEY="your-key"
   python build_knowledge_graph.py     → Interactive menu (5 options)
   
   Options:
   1. Load from vault files
   2. Select Claude model (Haiku=$1-2, Sonnet=$10-20)
   3. Start building with checkpoints
   4. Resume from checkpoints if interrupted
   5. Interactive query mode

C. NATIVE PYTHON PATH (Most Control):
   source venv/bin/activate
   python embedding_service.py &       → Terminal 1
   streamlit run streamlit_ui_enhanced.py → Terminal 2
   
D. RESUME INTERRUPTED BUILD:
   python retry_failed_chunks.py       → Auto-resumes from latest checkpoint

2. INITIALIZATION REQUIRED
================================================================================

ENVIRONMENT SETUP:
  • ANTHROPIC_API_KEY (required for Claude features)
  • OLLAMA_HOST (for local models, default: http://host.docker.internal:11434)
  • LLM_MODEL (default: qwen2.5-coder:14b)
  • EMBED_MODEL (default: nomic-embed-text)

DEPENDENCIES:
  Core: requirements.txt (Flask, Streamlit, ChromaDB, transformers)
  GraphRAG: requirements_graphrag.txt (adds GraphRAG, networkx, azure SDK)

DATABASE INITIALIZATION (Automatic):
  • ChromaDB: Auto-created in ./chroma_db/ on first run
  • Vector embeddings: Auto-downloaded (~90MB embedding model)
  • Graph data: Auto-created in ./graph_data/ with checkpoints
  • Ollama models: Must be pre-pulled (ollama pull <model>)

SERVICES THAT START:
  1. Embedding Service (port 8000) - Vector search backend
  2. Graph Service (port 8002) - GraphRAG/LightRAG backend
  3. Streamlit UI (port 8501) - Web interface
  4. External: Ollama (port 11434) - Must be running separately

  Ollama (port 11434)       Local LLM provider (required)

5. DOCKER COMPOSE SETUP
================================================================================

CONFIGURATION:
  docker-compose.yml contains 6+ services with profiles:
  
  DEFAULT SERVICES (always start):
    - embedding-service (port 8000)  Vector search
    - streamlit-ui (port 8501)       Web interface
  
  OPTIONAL PROFILES:
    --profile graphrag           Microsoft GraphRAG service
    --profile graphrag-local     Local Ollama GraphRAG
    --profile graphrag-claude    Claude-powered GraphRAG
    --profile lightrag           LightRAG (legacy)
    --profile graphrag-gpt-oss   Custom GPT model

QUICK COMMANDS:
  docker-compose up -d              Start default services
  docker-compose --profile graphrag up -d  Start with GraphRAG
  docker-compose down               Stop all services
  docker-compose down -v            Stop and remove volumes (wipe data)
  docker-compose ps                 List running services
  docker-compose logs -f            View logs
  
DATABASE VOLUMES:
  ./chroma_db/              ChromaDB vector embeddings
  ./graphrag_db/            GraphRAG indices
  ./graphrag_local_db/      Local GraphRAG data
  ./graphrag_claude_db/     Claude-powered GraphRAG data
  ./graph_data/             Graph checkpoints and final graph

7. TYPICAL USER JOURNEY (Step-by-Step)
================================================================================

INITIAL SETUP (One-time):
  1. Clone project
  2. Create .env.local with API keys
  3. Pull Ollama models: ollama pull qwen2.5-coder:14b && ollama pull nomic-embed-text
  4. Start Ollama in background: ollama serve

STARTING WORK:
  1. ./Scripts/docker_start.sh
  2. Wait 10 seconds for services to initialize
  3. Open browser: http://localhost:8501
  4. Click "Index Vault" button in sidebar (if first time)
  5. Select search mode from sidebar (7 options available)
  6. Enter query in main area
  7. View results with sources
  
STOPPING:
  1. ./Scripts/docker_stop.sh
  
TROUBLESHOOTING:
  1. ./Scripts/docker_status.sh          Check what's running
  2. docker-compose logs embedding-service  View logs
  3. Ensure Ollama is running: curl http://localhost:11434/api/tags

9. PERFORMANCE & COST EXPECTATIONS
================================================================================

BUILDING A KNOWLEDGE GRAPH (1600 notes):

With Claude Haiku:
  Cost: $1-2
  Time: 45-75 minutes
  Quality: Good for most use cases
  
With Claude Sonnet:
  Cost: $10-20
  Time: 60-90 minutes
  Quality: Premium (more accurate entity extraction)
  
With Ollama Local:
  Cost: $0
  Time: 2-3 hours+
  Quality: Depends on model size
  Requirements: More CPU/RAM

QUERYING:
  Vector search: <1 second
  Graph search: 5-10 seconds
  Hybrid search: 5-15 seconds

SYSTEM REQUIREMENTS:
  CPU: 2+ cores (4+ recommended for graph building)
  RAM: 8GB minimum (16GB recommended)
  Disk: 50GB for all data
  Internet: Only for API calls (Claude, Anthropic)
